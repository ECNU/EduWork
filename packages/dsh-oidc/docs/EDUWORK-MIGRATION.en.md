# Upgrading organization authentication

[简体中文](EDUWORK-MIGRATION.md) | **English**

The current source replaces Key Binding model access with token gateway authorization. Old model profiles are rejected; migrate explicit configuration and sign in again. Workspaces, conversations and personal provider settings are unchanged. Old model keys are neither adopted nor bulk-deleted. Use desktop/web Host services instead of the removed native account bridge.

See [migration steps](key-binding-protocol.en.md), [configuration](enterprise-profile.en.md) and [compatibility](compatibility.en.md).
