# 行为准则

**简体中文** | [English](CODE_OF_CONDUCT.en.md)

我们致力于维护专业、包容且无骚扰的项目环境。

参与者必须：

- 讨论观点和代码，而不是个人特征；
- 假设善意，同时接受基于证据的纠正；
- 保护私有安全报告、机构信息和个人数据；
- 避免骚扰、威胁、歧视性语言、性化行为、人肉搜索和持续扰乱；
- 尊重维护者为了保护用户、协议稳定性、许可证或安全而作出的决定。

当行为威胁贡献者或用户时，维护者可以编辑、隐藏、拒绝或删除贡献，也可以临时或永久限制参与。执行措施应当适度；适合时应私下记录，并避免暴露受害者或安全敏感细节。

一般行为问题可以创建不含个人敏感信息的 Issue。需要保密处理的骚扰、威胁、人肉搜索或其他行为事件，请使用 GitHub [Private Vulnerability Reporting](https://github.com/ecnu/EduWork/security/advisories/new)，并在标题中标注“Code of Conduct”。不要在公开渠道披露受影响者身份或证据附件。
