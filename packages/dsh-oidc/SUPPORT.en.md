# Support

[简体中文](SUPPORT.md) | **English**

Use [GitHub Issues](https://github.com/ecnu/EduWork/issues) for public integration questions. Use the private process in [`SECURITY.en.md`](SECURITY.en.md) for vulnerabilities and secrets.

When reporting a normal bug, include:

- `dsh-oidc`, Node.js, DSH, and pi-ai versions;
- Web or native backend and Credential Provider type;
- sanitized Enterprise Profile with all real domains/IDs replaced;
- expected and observed behavior;
- minimal reproduction and redacted logs.

The project does not support shared multi-user Web deployment, unreviewed DSH versions, private Provider adapters selected by profiles, or production secrets posted publicly.
