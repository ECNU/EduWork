# 支持

**简体中文** | [English](SUPPORT.en.md)

普通集成问题请使用 [GitHub Issues](https://github.com/ecnu/EduWork/issues)。漏洞和秘密信息请使用[安全政策](SECURITY.md)规定的私有流程。

报告普通缺陷时，请提供：

- `dsh-oidc`、Node.js、DSH 和 pi-ai 版本；
- Web 或 native 后端，以及 Credential Provider 类型；
- 已将真实域名和 ID 全部替换的脱敏 Enterprise Profile；
- 预期行为和实际行为；
- 最小复现和脱敏日志。

项目不支持以下情形：共享多用户 Web 部署；未经审查的 DSH 版本；由 Profile 选择的私有 Provider adapter；在公开渠道提交生产秘密。
