# 变更记录 / Changelog

## 0.1.0

- 首次独立打包，提供桌宠设置、状态与动画、内置小页（红、蓝）、大肥鱼和小花狮。
- 依赖兼容的 DSH 0.2 API 与 EduWork Electron 桌面桥接；悬浮窗口及通知事项由宿主提供。
- 保留原有插件标识、设置和桌宠行为。

- Initial standalone package with settings, state and animation, and four built-in characters: Page (red and blue), Dafeiyu and Huashi.
- Requires compatible DSH 0.2 APIs and the EduWork Electron desktop bridge; the host provides the floating window and notification items.
- Preserves the existing plugin identity, settings and pet behavior.
