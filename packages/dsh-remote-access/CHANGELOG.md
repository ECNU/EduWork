# 变更记录 / Changelog

## 未发布 / Unreleased

- 首个版本：DSH 插件与设置页、自托管中继服务和网页客户端；端到端加密，本机确认配对码，可逐台移除设备。
- First version: the DSH plugin and its settings page, a self-hosted relay and the web client; end-to-end encrypted, pairing confirmed by code on the computer, devices removable one by one.
- 中继可凭机构登录的 ID Token 接纳电脑，并限制注册频率、每个账号的电脑数和每台电脑的连接频率；发行版可预置机构的中继与登录，用户登录后即可使用。
- The relay can admit computers by the ID Token of an organization's sign-in, and limits refused registrations, computers per account and connections per computer; a distribution can preset its organization's relay and sign-in, ready once the user signs in.
