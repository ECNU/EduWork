# 极值图论问题变体清单

当用户围绕“禁用某类子图，最大化某个量”寻找研究问题时，使用这份清单
补充 `discover-math-problems` 的候选生成步骤。候选排序、文献核对和后续
研究记录继续遵循 [主流程](../SKILL.md)。

## 先明确原问题

- 图的范围：简单图或其他模型，有无方向，是否限制为二部图、平面图等。
- 禁用条件：一个图或图族，禁止普通子图还是诱导子图。
- 优化对象：边数、固定图的拷贝数、谱半径等；计数时区分带标号与不带标号。
- 参数与目标：哪些参数固定、哪些增长，要求精确值、渐近界、构造还是稳定性。
- 用户希望保留的中心对象、已知结果和可使用的方法。

## 可尝试的变体

这些是候选生成方式，顺序不代表难度或发表机会。

| 改动方向 | 示例 | 需要核对 |
| --- | --- | --- |
| 改禁用图的参数 | `C_k` 换成 `C_{k+1}`，`K_r` 换成 `K_{r+1}`，`P_k` 换成 `P_{k+1}` | 参数变化是否落入已有定理，奇偶性或其他结构条件是否改变 |
| 改禁用图或图族 | 比较禁用 `C_4` 与禁用 `K_{2,3}`；单个禁用图换成 `{C_4, C_5}` | 新旧限制的包含关系，新增条件是否冗余 |
| 改计数对象 | 边数换成三角形、`K_4`、`C_5` 或一般固定图的拷贝数 | 计数约定，目标结构是否已被禁用条件排除 |
| 改优化量 | 边数换成谱半径，或在给定最小度条件下最大化边数 | 谱矩阵的定义；这是新目标还是新增约束 |
| 改图类 | 一般图限制为二部图或平面图 | 新图类与目标结构是否相容，已有界或构造能否直接适用 |
| 增加一个固定条件 | 固定顶点数和边数后最大化某种结构的数量 | 可行图是否存在，目标是否被固定条件完全决定 |

先检查候选是否有实际内容。例如，二部图中的三角形数恒为零；若同时固定
边数并以边数为目标，优化量也已经固定。这类检查应在推荐前完成。

## 筛选与说明

1. 先保留原问题的主要结构，生成少量可比较的候选；说明每个候选具体改了什么。
2. 检索当前文献，核对最接近结果的假设、参数范围与结论。引用前核对标题、
   作者、年份和可访问来源，并说明候选与已有结果的具体差别。
3. 未完成文献核对时，不得声称问题是新的或仍然开放。不能检索的候选标记为
   `unverified`，说明需要补查哪些结果。
4. 结合已知构造、上界方法和用户的研究条件判断可行性；列出尚未解决的关键
   步骤，以及何种已有结果或反例会使这个候选失去继续研究的价值。
5. 难度依据当前证据说明，不预设某种改动“容易出成果”，也不一概排除超图、
   flag algebra、正则方法、吸收法或 Ramsey–Turán 问题。若用户偏好小改动，
   将其作为本次筛选偏好。

将通过初步筛选的方向放入现有 `problem_menu`。每项给出明确问题、相对原题
的改动、最接近的已核对结果、方法设想与缺口，以及下一步检查。
用户只要简短建议时，可给一个主要候选和一个备选；不必另建一套报告格式。
