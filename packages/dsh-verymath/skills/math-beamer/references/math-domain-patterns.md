# Mathematical Domain Patterns

Use this file to choose slide structure by mathematical domain.

## Core Pure Mathematics

- **Theorem/proof talks:** motivation, definitions, examples, theorem,
  proof roadmap, key lemma, proof sketch, sharpness, limitations.
- **Algebra:** objects, morphisms, examples/non-examples, structure theorem,
  diagram of implications, computational examples.
- **Number theory:** problem statement, local/global conditions, examples,
  main theorem, method, error terms or density statements.
- **Combinatorics and graph theory:** objects, forbidden configurations,
  extremal parameter, random model when relevant, proof method, examples.
- **Logic, foundations, and category theory:** formal system or category,
  syntax/semantics, universe or size convention, functorial maps, coherence.
- **Geometry/topology:** visual intuition, definitions, invariants, local
  models, diagrams, theorem, proof idea, examples.
- **Core analysis:** spaces, norms, operators, convergence mode, estimates,
  limiting argument, examples and counterexamples.
- **PDE:** function spaces, assumptions, estimates, compactness or fixed-point
  route, boundary/initial conditions, weak formulation, regularity.

## Applied And Computational Mathematics

- **Optimization:** model, assumptions, algorithm, convergence theorem, rate,
  numerical evidence, failure modes.
- **Numerical analysis:** continuous problem, discretization, stability,
  consistency, convergence, implementation, experiments.
- **Scientific computing:** equation/model, computational pipeline, solver,
  reproducibility, metrics, figures, limitations.
- **Dynamical systems:** phase space, invariant sets, stability notion,
  bifurcation parameter, qualitative diagram, theorem or experiment.
- **Control systems:** state/input/output model, controller class,
  controllability or observability, Lyapunov or frequency-domain argument,
  robustness margins.
- **Information, coding, and cryptography:** source/channel/adversary model,
  code or protocol, rate/security parameter, theorem, proof reduction.

## Probability, Statistics, Data

- **Probability:** sample space, filtration, random objects, main inequality or
  limit theorem, proof idea, examples.
- **Statistics:** model, estimator, assumptions, data, theorem or guarantee,
  diagnostics, uncertainty, limitations.
- **Machine learning theory:** objective, architecture or hypothesis class,
  assumptions, bound, proof route, empirical check.

## Teaching And Survey

- **Course lecture:** one concept per slide, worked example, common mistake,
  exercise, recap.
- **Reading group:** paper question, contribution, assumptions, theorem map,
  proof dependencies, unclear points.
- **Survey:** taxonomy, comparison table, representative theorem, open
  problems, reading route.
