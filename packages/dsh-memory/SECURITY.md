# Security

Do not post credentials, personal memory exports, session logs or private database files in public issues. Report suspected vulnerabilities through the repository's private vulnerability reporting feature if enabled; otherwise contact the maintainer privately before sharing sensitive details.

Memory is local but not encrypted by this plugin. Protect the operating-system account and backups. Redaction is best-effort and not a replacement for avoiding secrets. Sources and historical excerpts are untrusted data, not instructions.

The plugin does not upload memory to a synchronization service. Relevant retrieved facts/excerpts can enter the active model context and therefore be sent to the model provider selected in DSH.

Imports are user-initiated data operations. They may merge records, restore retention and explicitly override matching forget markers. A semantic export does not carry the forget-marker list.

Only the current stable package is maintained. Review package identity, version, tarball integrity and source commit before installation.
