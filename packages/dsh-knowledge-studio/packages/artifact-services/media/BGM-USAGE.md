# BGM 使用与来源

本库六首均为本项目 AI 辅助编写曲谱和合成代码、本机确定性渲染的纯器乐循环素材。没有调用音乐音频生成 API，没有使用第三方录音采样，没有指定仿作某位艺人或某首作品。

| ID | 用途 | BPM | 时长 |
| --- | --- | ---: | ---: |
| quiet-explanation | 安静讲解、课程 | 80 | 48 秒 |
| warm-campus | 校园、人文 | 92 | 41.74 秒 |
| digital-pulse | 科技、产品介绍 | 112 | 34.29 秒 |
| bright-day | 轻快日常、活动 | 104 | 36.92 秒 |
| reading-room | 阅读、专注 | 64 | 60 秒 |
| steady-story | 纪录、汇报叙事 | 88 | 43.64 秒 |

谱面与合成脚本按项目 MIT 许可证提供；在存在可授予权利的范围内，生成录音同样按项目 MIT 许可证提供，可用于项目和成果，并保留许可说明。此说明不是对各法域可版权性、唯一性或不侵权的法律保证。不要标注为“AI 生成所以没有版权”。

复现：使用 Python 与 NumPy 运行 `compose_bgm.py --output <临时目录>`，在该目录生成 PCM 母版 `bgm/*.wav`、`bgm/catalog.json` 和 `scores/*.json`。再运行 `node encode_bgm.mjs <FFmpeg路径> <临时目录>/bgm <发布目录>/bgm`，使用 libmp3lame 编码为 192 kbps MP3，独立解码后检查时长、音量、削波和循环边界，并更新目录及 SHA-256。编码脚本不覆盖已存在的 MP3；请在空目录生成并验收后替换。只有明确更新曲库时才运行。曲谱中保留音高、起点、长度、音色、音量和声像。

发布规格：192 kbps MP3、32 kHz、立体声，保留无缝解码所需的 Xing/LAME 延迟和补齐信息。六首合计约 6.1 MiB；不随发布包携带约 32.3 MiB 的 PCM 母版，母版可以从曲谱与脚本重建，原 SHA-256 和测量值保留在 catalog 的 `pcmMaster`。MP3 独立解码时长与母版逐样本一致，平均电平约 −18.68 dBFS（母版 −18.42 dBFS），检测无削波，循环边界样本幅值差低于 0.004。默认 BGM 音量 0.16、旁白期间 0.06 保持不变；对话视频工具与 Studio 读取同一个目录及曲目 ID。循环效果取决于播放器是否尊重无缝元数据，实际渲染另行回归。技术检查不等于听感评审；本库属于轻量合成配乐，可按场景试听选择。
