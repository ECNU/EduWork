# 图像创作

使用 `image_providers` 查询实际可用的提供方、原生尺寸、输出格式和适配能力。通过 `image_generate` 完成生图；只有一个可用提供方时可以省略 `provider`，有多个时明确选择。用户指定的提供方不可用时说明原因，不悄悄换服务。

提示词说明主体、构图、用途、风格、颜色和必须保留的文字。沿用用户已经明确的要求；只追问影响结果且无法推断的信息。请求精确尺寸时用 `size`，例如 `1920x1080`；先看能力目录，不将某个服务的原生尺寸写成通用限制。提供方支持尺寸适配时，`fit: crop` 表示填满画面并裁切边缘，`fit: pad` 表示保留整幅画面并补边。涉及边缘文字或完整图形时优先保留完整内容。

生成完成后使用工具返回的真实文件。检查实际尺寸和 `resized`；如有 `sourceRelativePath`，保留原始生成图。若返回 `resizeWarning`，明确告知尺寸适配未完成，并交付仍可用的原图；不要把原图说成已达到目标尺寸。失败时根据工具信息调整参数，不无限重复调用或声称成功。

图像可以作为 Office、视频或 Studio 成果的素材；仍复用这一入口，不为某个学校另建生图方法。Studio 负责组织成果，机构扩展负责提供方和凭据。不要直接请求服务端、读取密钥或绕过被拒绝的工具调用。工具权限门禁负责本次操作的许可，无需自行重复索取许可。
