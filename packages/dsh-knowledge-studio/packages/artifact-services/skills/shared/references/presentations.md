# 演示内容规范

先组织故事线，每页一个主要结论，屏显文字简洁，完整背景、论证和解释保留在讲者备注。阅读型文稿需具备独立阅读所需信息；演讲型文稿支持现场讲述。常见故事线为背景、问题、方案、证据、下一步，按真实用途调整。

按内容选择共享语义版式：并列比较用 two-column，真实数值用 metrics，时间顺序用 timeline，能力组成用 feature-grid，实施阶段用 roadmap，少量要点用 bullets。避免连续重复版式，不为凑版式编造指标或时间。标题尽量简短，过长解释进入备注；必须展示的完整内容由共享排版换行或续页，不能删减。

主题遵循用户要求或已有模板，缺省采用 modern-clean；主题会实质影响结果且无法推断时才追问。整套保持主题与层级一致。条目数、叙事比例和模板质量提示是建议，不是内容删除规则。准确的字段、版式和主题约定见 presentations/references/presentation-spec.md 与 profile-library.md。
