# 音视频内容与同步规范

先确定受众、表达目的、音频风格或视频比例，遵循用户选择的配音、字幕和 BGM。BGM 默认关闭。讲解使用自然口语和完整句意；对谈的 A/B 角色应有明确分工，避免机械复述。视频每场景一个主要信息，屏显要点简短，详细解释放入旁白；不用密集文字代替分镜，不为凑场景数增加空内容。

音色和音乐使用提供方实际返回的目录，保留用户选择，不编造音色或静默替换服务。精确旁白文本作为唯一配音依据，字幕使用同一文本。实际音频时长驱动场景与字幕时间轴，不凭字数猜测或伪造逐字时间戳；当前为句/分段同步。修改文本、语速或音色后重新建立对应音频绑定。

无配音时不请求语音服务；是否需要无声文字说明由用户要求决定。混音、分段和音量规则交给共享媒体服务，不在提示词中另维护时间常数。BGM 使用已登记且有来源许可信息的素材，不以 AI 生成推定没有版权。

检查实际音视频文件的完整播放、声音、字幕边界和比例。视频检查关键帧，具备播放条件时试听；未试听应明确。源码工程与结构化模板是不同创作方式，遵守同一内容与验收要求，但不声称两者具有相同布局能力。
