# 语音创作

创作前阅读[共同规范](../shared/references/common.md)和[本类创作规范](../shared/references/media.md)。这些文件同时用于 Studio 生成；此处只补充工具操作。

先确定精确的朗读文本。调用 `speech_voices` 查询实际可用的提供方、音色和背景音乐；不要凭记忆编造音色目录。调用 `speech_synthesize` 时提供 `text`、`provider`、`voice`，可选 `speed`。音频统一为 WAV，时长来自实际文件。

用户指定音色时保持不变；缺失音色时报告不可用，不悄悄换服务。必要时用相同接口合成一句短试听。只有影响结果且无法从已有要求推断的信息才需要追问。

视频场景编排由 artifact-video 工作流处理；这里仅提供精确文本的语音与转写操作。

工具负责权限、凭据和文件落地。不要直接请求服务端、读取密钥、绕过被拒绝的工具调用，或声称本地语音需要校园账号。最终交付工具返回的文件路径。

音频概览与双人对谈可调用 `media_render`，指定音色 A/B、字幕和可选 BGM。纯音频也复用相同的时间轴与混音规则。

用户提供已有音频并要求转写时，先调用 `speech_transcription_providers` 检查已就绪的提供方，再用 `speech_transcribe` 读取获准的工作区音频。保持用户指定的提供方，不自动下载识别模型、安装依赖或静默改用另一服务。提供方未就绪时说明实际缺项；交付工具返回的转写文本与文件，不把 TTS 音色当成语音识别能力。
