# 变更记录 / Changelog

## 0.1.0 — 2026-11-02

- 首次发布 SystemOne 兼容的决策工具与技能，支持结构化返回、超时及取消。
- 支持显式 API Key、可选 OIDC 和免鉴权服务配置，默认关闭，由用户配置后启用。
- Initial release of SystemOne-compatible decision tools and skill with structured results, timeout and cancellation.
- Support explicit API keys, optional OIDC and unauthenticated services; disabled until configured and enabled.
