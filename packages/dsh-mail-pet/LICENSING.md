# 许可范围

**简体中文** | [English](LICENSING.en.md)

本目录的主许可证为木兰宽松许可证第 2 版（`MulanPSL-2.0`），全文见 [LICENSE](LICENSE)。

本包在仓库切换到木兰许可之后引入，因此全部原创代码按木兰许可提交。仓库在切换之前的 MIT 贡献仍保留原授权，原许可全文保留在 [LICENSE-MIT](LICENSE-MIT)：本包的 `lib/watcher.js` 与 `lib/message.js` 的早期版本曾在 MIT 阶段以 PR 形式提交，历史 Git 记录与作者归属继续有效。

后续分发如果同时包含木兰许可贡献与历史 MIT 代码，须保留两份许可证及相关声明。因此本包的 SPDX 表达式为 `MulanPSL-2.0 AND MIT`，表示不同来源代码各自适用的义务，并非所有代码可任选一种许可。历史 MIT 贡献者不会仅因本次切换被视为作出了新的木兰专利授权。

新增原创贡献按木兰许可提交；投稿者应确认自己有权授予其贡献中涉及的版权和专利许可。引入的第三方代码继续保留原许可证、版权及来源，不适用此默认规则；本包运行时依赖 `imapflow`（MIT），见其自身许可声明。
