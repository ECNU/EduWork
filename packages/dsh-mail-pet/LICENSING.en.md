The primary license for this directory is the Mulan Permissive Software License, Version 2 (`MulanPSL-2.0`); the full text is in [LICENSE](LICENSE).

This package was introduced after the repository moved to the Mulan license, so all original code here is contributed under it. MIT contributions made before the switch keep their original grant, and that text is retained in [LICENSE-MIT](LICENSE-MIT): early versions of this package's `lib/watcher.js` and `lib/message.js` were submitted as pull requests during the MIT period, and the historical Git record and authorship remain effective.

A distribution that carries both Mulan-licensed and historical MIT code must keep both licenses and their notices. The SPDX expression for this source module is therefore `MulanPSL-2.0 AND MIT`, which states the obligations that apply to code from each origin rather than a choice between either license. Historical MIT contributors are not treated as granting a new Mulan patent license merely because of the switch.

New original contributions are submitted under the Mulan license; contributors should confirm they can grant the copyright and patent licenses involved. Third-party code keeps its own license, copyright and provenance and is not covered by this default; this package depends on `imapflow` (MIT) at runtime, per its own notices.
