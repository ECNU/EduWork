# 外部智能体连接

[English](README_EN.md)

EduWork 的可选插件：发现本机 Codex、Cursor Agent CLI，在设置中检测、启用和停用连接，也可手动添加支持 stdio 的 ACP 智能体。兼容 DSH 0.2.1-rc.5 与 0.2.2-rc.1；配套官方 Codex/ACP provider 必须与宿主版本一致。

## 安装与使用

1. 提供本插件的预装版本：打开左侧“插件 → EduWork 扩展”，启用“外部智能体”，点击“配置”。首次预装默认关闭，停用保留连接设置；已有用户选择不会因升级而重置。源码试用可按[构建指南](DEVELOPMENT.md)准备插件，再通过插件页从本地目录安装。
2. 配置表单也可从“设置 → 外部智能体”或独立 DSH 的插件详情页打开。扫描只检查常见安装目录和 PATH，不执行程序；发现的路径是候选项，请确认来自你信任的安装。
3. 先在智能体自己的入口登录，再点击“检测连接”，成功后手动启用。主模型登录不等于智能体登录，插件不保存或转发登录凭据。
4. 在主聊天请求委派，例如“请用 subagent_codex 分析这段文字”。任务、子代理列表和结果通知沿用 DSH，不新增独立调度器或任务面板。

Codex 使用 DSH 官方包固定的 Codex 运行时及本机登录；发现的 CLI 路径仅供参考，不替换官方运行时。若已有官方 Codex bundle，请先停用它，避免重复注册 provider。Cursor 需要 Agent CLI，仅安装编辑器不足以连接。

其他 ACP 在“添加 ACP”中填写名称、可执行文件绝对路径和 JSON 参数数组，例如 `["acp"]`。保存不会启动程序；检测只发送 `initialize`，不创建会话、不发送任务。握手成功不代表登录或真实任务可用。不要把密钥放入参数。

## 能力边界

- 连接设置通过 DSH storage domain 保存，启用状态重启恢复；检测结果不持久化。新连接默认停用，检测通过后才能启用。
- 停用阻止新任务；已开始的任务继续由 DSH 管理。停用后可以移除手动添加的连接。恢复失败的条目仍能停用，不阻塞其他连接。
- Codex 使用 `permissionMode: never`，ACP 使用 `permission: reject`；这是拒绝交互授权，不是强制只读或独立文件系统沙箱。任务权限与工作区语义由官方 provider 决定。
- 插件只增加发现、连接检测与配置界面；委派、进程回收、权限、会话隔离和结果回传使用官方 provider、subprocess 与 tool-subagent。设置使用官方 slot、locale、Typert remote，默认访问权限不扩宽。
- 当前面向本机桌面 Host，不支持远端主机发现、自动安装或登录、任务续接。macOS 为首个验收平台，Windows/Linux 尚需原生验收。

开发与测试见[构建指南](DEVELOPMENT.md)。
