# 安全政策

**简体中文** | [English](SECURITY.en.md)

`@eduwork/dsh-mail@0.1.1` 已面向 DeepSeek Harness `0.1.5-rc.1` 完成代码、自动化测试和无网络运行时验收。连接重要邮箱前，仍应完成组织自己的安全、合规与恢复方案审查。

如发现授权绕过、凭据泄露、工作区逃逸、邮件状态意外修改、审批绕过、重复发信或远程代码执行风险，请不要公开 issue。请通过 GitHub [Private Vulnerability Reporting](https://github.com/ecnu/EduWork/security/advisories/new) 私密报告。

报告请只包含最小复现步骤、受影响版本和脱敏后的协议事实。不要附上真实授权码、Cookie、完整邮件、个人地址或未清理的诊断包。

我们会确认收到、评估影响、准备修复和回归测试，再协商披露时间。项目不承诺固定 SLA，但会优先处理可导致外发、凭据或工作区越界的问题。
