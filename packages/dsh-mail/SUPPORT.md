# 支持

**简体中文** | [English](SUPPORT.en.md)

普通安装、兼容性和协议问题请使用 [GitHub Issues](https://github.com/ecnu/EduWork/issues)。漏洞、授权码、真实邮件或私有服务器信息必须走[安全政策](SECURITY.md)规定的私密流程。

普通缺陷报告请提供：

- `dsh-mail-assistant`、DSH、Node.js 和操作系统版本；
- Web 或桌面宿主、权限预设及 Filesystem Provider 类型；
- IMAP/SMTP 类型、端口、TLS 模式和认证方式，不要提供真实主机与账号；
- 预期行为、实际行为和最小复现；
- 已删除地址、主题、正文、Message-ID、授权码和服务端响应的脱敏日志。

当前不支持 OAuth2 邮箱认证、多账号、共享多用户 Web、后台轮询、删除/移动邮件、计划发送，以及未经复核的 DSH 版本。邮箱服务商是否允许应用密码或 SMTP AUTH 属于其租户策略，不由本插件控制。
