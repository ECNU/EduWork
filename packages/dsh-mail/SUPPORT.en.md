# Support

[简体中文](SUPPORT.md) | **English**

Use [GitHub Issues](https://github.com/ecnu/EduWork/issues) for normal installation, compatibility, and protocol questions. Vulnerabilities, app passwords, real messages, and private server information must use the private process in the [security policy](SECURITY.en.md).

For an ordinary defect include:

- `dsh-mail-assistant`, DSH, Node.js, and operating-system versions;
- Web or desktop host, permission preset, and Filesystem Provider type;
- IMAP/SMTP class, port, TLS mode, and authentication method without real hosts or accounts;
- expected behavior, observed behavior, and a minimal reproduction;
- sanitized logs with addresses, subjects, bodies, Message-IDs, app passwords, and server responses removed.

OAuth2 mailbox authentication, multiple accounts, shared multi-user Web, polling, delete/move, scheduled sending, and unreviewed DSH versions are outside the current support boundary. Provider policy for app passwords or SMTP AUTH is not controlled by this plugin.
