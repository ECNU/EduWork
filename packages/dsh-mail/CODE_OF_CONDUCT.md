# 行为准则

**简体中文** | [English](CODE_OF_CONDUCT.en.md)

我们致力于维护专业、包容且无骚扰的项目环境。

参与者必须：

- 讨论观点、协议和代码，而不是个人特征；
- 假设善意，同时接受基于证据的纠正；
- 保护私有安全报告、邮件数据、账号配置和个人信息；
- 避免骚扰、威胁、歧视性语言、性化行为、人肉搜索和持续扰乱；
- 尊重维护者为保护用户、邮件边界、许可证或供应链安全作出的决定。

当行为威胁贡献者或用户时，维护者可以编辑、隐藏、拒绝或删除贡献，也可以临时或永久限制参与。措施应适度，并避免暴露受影响者或安全敏感材料。

一般行为问题可以创建不含个人信息的 Issue。需要保密处理的骚扰、威胁、人肉搜索或其他事件，请使用 GitHub [Private Vulnerability Reporting](https://github.com/ecnu/EduWork/security/advisories/new)，并在标题中标注“Code of Conduct”。
