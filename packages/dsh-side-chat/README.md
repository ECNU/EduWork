# 临时侧边聊天

**简体中文** | [English](README_EN.md)

从原会话的一条用户消息或已完成的助手回答开启临时侧聊，在原生右侧栏使用同一套聊天组件。侧聊通过标准 seed fork 继承来源历史作为模型上下文，UI 层隐藏继承的消息，只展示侧聊新增的内容。

侧聊关闭后停止生成，并通过 DSH 的公开 Workspace 归档接口归档；消息记录与工作区归属保留，可在归档会话中查看或恢复为普通会话。作为普通会话打开时，也会显示继承的来源历史。切换主会话、收起、隐藏窗口和长时间不活动不会结束侧聊。刷新或窗口退出时请求归档；强制终止导致请求未送达时，持久化记录仍会保留，可能作为未归档普通会话出现。草稿不作恢复保证。已执行的文件修改和外部操作不会随关闭撤销。

每个主会话可同时保留多个侧聊，各自固定继承创建时的历史快照。引用时优先选择当前聚焦且包含所引用内容的侧聊；否则按创建顺序选择可覆盖内容的侧聊，若没有则创建新侧聊。流式回复的选段以可见文字快照判断覆盖，并作为引用上下文随提问发送；超过 100,000 字符时仅保留选段及邻近上下文，且保守地创建新侧聊。切换主会话时恢复对应的侧聊、消息、草稿和批注。不支持转正、侧聊内再分叉、子代理、定时任务和长期后台工作。工具仍遵守新会话的权限，生成仍遵守全局并发规则。

在 EduWork 中，侧聊不发送完成和失败通知，归档后恢复为普通会话也保持这一行为；需要用户授权或回答的问题仍会提醒。

## 架构

本插件通过 cordis 注册，不修改 Runtime 或 UI bundle。关闭使用 `workspaceRegistry.archiveSession`，不读取或删除持久化后端文件；界面隐藏继承历史仍依赖原生 DOM 标记。宿主须提供 Workspace 归档服务。

- **Host 端** (`src/index.js` + `src/service.js`)：通过 `agents.create({ seed })` 标准 API 创建 seeded session，`/api/eduwork/side-chat` 管理创建、所有权和关闭
- **客户端** (`src/client/`)：注册侧栏 tab、资源协议、消息操作按钮，通过 DOM 隐藏继承消息
- **边界** (`src/boundary.js`)：system prompt 约束和工具拦截
