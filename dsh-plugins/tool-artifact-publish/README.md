# 发布已有成果文件

[English](README_EN.md)

为在外部工具中创建的工作区文件提供 DSH 成果展示元数据。工具只读取并校验已存在的项目相对路径，不复制、生成或修改文件。

成功结果通过 DSH 的工具展示接口进入成果卡片，便于预览和下载。

0.1.7 候选使用独立的 `/native` 入口：已有文件由官方 `present` 工具登记；产品的图像、语音、视频与 Office 工具成功后，由适配器核验文件并记录官方持久成果事件。候选不再注册重复的 `artifact_publish` 工具或自有成果卡片。失败、取消和不在当前工作区内的输出不会登记；嵌套调用须等待外层成功。默认入口继续供旧内核使用。
