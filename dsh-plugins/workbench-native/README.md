# 工作台服务

[English](README_EN.md)

提供通用技能管理、桌面更新与诊断入口。技能中心读取实际技能目录，不要求机构登录；桌面能力复用经过认证的宿主边界服务。

## 自动更新与诊断

发现更新后，左下角显示蓝色小按钮；下载期间显示进度，完成后提供重启安装。设置与托盘进入同一个更新面板，关闭面板不会中断下载。

设置中「检查更新」位于标题右侧；开发版和公测版使用主题色按钮选择，操作繁忙时禁用冲突操作。切换渠道不降级、不改变已安装版本徽标，开发渠道也接收更新的公测版。诊断导出包含组件、启动与更新信息以及脱敏日志；会话正文单独导出。

## 导入历史数据

选择旧客户端的程序根目录（含 `data/`），并先退出旧客户端。支持 `data/dsh` 以及 Wails/Electron 发行数据目录。程序先复制日志到隔离区，通过官方持久化接口读取 JSONL/Zstd，从不运行旧客户端插件。

导入合并会话、程序目录内的工作区和附件；重复内容跳过，冲突会话生成新 ID，冲突文件保留新副本。跨机缺少外部工作区时保留聊天历史并建立空工作区占位，提示另行复制原文件。配置与登录不变；浏览器缓存、日志和 Memory 数据库不在该导入范围内。

选择目录使用官方 `uiWorkspace.pickDirectory` 或 Go `Startup.PickDirectory`。`inspectImport` 返回检查状态，`ready` 后可用 `importData(id)` 确认，或取消；确认之前只使用隔离暂存区。按日志头与记录体版本判断兼容性，未知版本明确报错，不静默忽略，也不以旧副本替代无法读取的新日志。结果存于 `dsh/imports`，当前任务结束后重新打开会话。

## 模型请求并发

提供当前 Host 的总并发设置，默认 3 路；主会话、子代理与辅助请求共用上限。旧子代理限制兼容迁移到总并发，具体规则见[并发控制](../request-concurrency/README.md)。

## 验证

通过 `EDUWORK_TEST_RUNTIME` 指定准备好的 DSH Runtime，运行 `node --test test/*.test.mjs`。`test/import-browser.mjs` 使用真实 React 界面、严格的导入模式和 Edge；需要准备 `main.cache/client-build-tools` 中的 TypeScript 构建工具。测试仅使用合成数据。
