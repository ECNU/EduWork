# 组件与版本界面

[English](README_EN.md)

在 DSH 官方“插件”设置区增加“组件与版本”页。页面只读展示发行版、DSH Core、Node/pnpm 版本，以及产品平台、代码运行时和能力环境的就绪状态。

DSH 官方 `插件列表` 继续负责 Loader 插件、启用状态和 Fiber 生命周期；官方 `插件配置` 继续负责配置。本页不再重复展示插件清单，只保留产品运行环境与桌面社区插件生命周期入口。

本机 Web 只显示可用运行环境，不展示依赖原生文件选择器和桌面重启接口的社区插件管理区；这些操作仍由桌面发行装配提供。本机 Web 无须创建桌面桥。

`build-client.ps1` 接受锁定源码的 `Upstream`、`DshLockPath` 和产物目录 `Output`。组件沿用官方插件设置插槽，无需复制另一套组件目录。
