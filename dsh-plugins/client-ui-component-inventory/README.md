# 关于与社区插件界面

[English](README_EN.md)

通过 `settings.section` 增加独立的「关于」页。公版与机构版复用同一页面：顶部显示当前产品名称和版本，下方展示 Electron、DSH Core、Node.js、Python 等运行环境及能力环境的版本、来源和就绪状态。旧回执中的产品平台信息仍能读取，但不重复展示产品版本。

品牌图标通过 `settings.about.brand` 子插槽复用现有品牌组件。GitHub 按钮指向公版仓库，反馈问题使用系统浏览器打开公版问题模板，只预填产品名称、版本、平台和 DSH Core 版本；不会附带日志、路径、配置或凭据。仓库也提供功能建议模板。

DSH 官方「插件列表」继续负责 Loader 插件、启用状态和 Fiber 生命周期；「插件配置」继续负责配置。若桌面装配提供可用的社区插件管理服务，「插件」下会单独显示「社区插件」页，保留安装、更新、移除和重启操作。当前默认装配不包含该后端，因此不会显示此入口；「关于」页不依赖它。

本机 Web 展示源码运行环境，不展示依赖原生文件选择器和桌面重启接口的社区插件管理区。本机 Web 无须创建桌面桥。

`build-client.ps1` 接受锁定源码的 `Upstream`、`DshLockPath` 和产物目录 `Output`，无需修改上游设置框架。
