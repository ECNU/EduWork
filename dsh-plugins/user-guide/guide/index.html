EduWork 使用教程

EduWork 是运行在你电脑上的工作助手：读写工作区里的文件、处理文档与表格、检索资料，并把每一步过程展示出来。

01认识 EduWork

你用自然语言描述任务，它会规划步骤、调用工具、修改文件，直到完成。会话、文件和设置都保存在本机；只有发给模型的内容会发送到你选择的模型服务。

02开始使用

  1. 配置模型。打开设置 → 模型，选择服务商，填写 API Key、接口地址和模型。发行方预置了模型或企业登录的版本，可以跳过这一步。
  2. 选择工作区。选一个文件夹作为工作区，它只在其中读写文件。
  3. 开始对话。在输入框里说明任务，按回车发送。

03界面一览

  1. 1新会话：开始一个新任务
  2. 2技能与插件：查看、启用和管理
  3. 3工作区：按文件夹分组的会话
  4. 4对话区：任务过程与结果
  5. 5附件、权限、模型与推理等级、发送
  6. 6右侧文件栏：右上角按钮展开

04第一次对话

写明要做什么、相关文件在哪、怎样算完成。可以用＋添加附件，输入 @ 引用工作区里的文件或其他对话，输入 / 调用指令和技能。

把 data 文件夹里的三份问卷 CSV 合并，按班级统计平均分，画一张柱状图，结果存成 summary.xlsx。

三种权限

权限能做什么适合
仅可查看读取文件、回答问题，不修改任何东西先了解一个陌生项目
工作区内修改在工作区里新建、修改文件和运行命令日常使用
完全权限可以访问工作区以外的位置你清楚任务会碰到哪些文件时
慎用完全权限

完全权限下它能改工作区以外的文件，甚至系统设置。拿不准时请用工作区内修改。

一个会话做一件事

每次继续对话都要把这个会话的历史发给模型，会话越长越慢、越费用量。一个阶段做完就新开会话；也可以输入 /compact 把前面的历史压缩成摘要。想先看方案再动手，输入 /plan。

05会话与工作区

  • 归属：会话属于它创建时所在的工作区。
  • 整理：侧栏会话可以置顶、分叉和归档，归档后历史仍然保留。
  • 移除工作区：只移除登记，不删除文件夹、文件或会话。
  • 附件：适合文本、表格、文档、PDF 和图片；程序专用格式请先导出为通用格式。

06技能与插件

侧栏的技能页列出可用技能，例如 Word、演示文稿、表格和 PDF。技能会在需要时自动使用，也可以输入 / 手动调用。插件页可以安装社区插件，请只安装你信任的插件。

07设置与更新

  • 通用：外观、字体大小、新会话的默认权限、模型请求总并发、故障诊断。
  • 模型：服务商、API Key 与模型。

在菜单或托盘里检查更新，下载后重启即可安装，会话和设置都会保留。

08常见问题

发消息后很久没反应，或提示 Connection error

先新开一个会话试试。只有老会话出错，多半是会话太长，输入 /compact 压缩或新开会话。新会话也出错，检查网络、代理和模型配置。

反馈问题时要附什么

写清楚系统版本、操作步骤和看到的错误，并在设置 → 通用 → 故障诊断导出诊断包一并提供。

09数据与隐私

  • 会话、文件和记忆都保存在你的电脑上。
  • 你发给模型的内容，以及任务需要时读取的文件，会发送到所选的模型服务。请不要处理未经授权的敏感数据。
