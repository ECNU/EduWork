EduWork 快速入门

准备一份课程讲义，用它做一页复习提纲。

  1. 连接模型

    打开「设置 → 模型」，填写模型服务商提供的 API Key、接口地址和模型名称。如果你的机构提供登录入口，也可以登录后选择已获授权的模型。

  2. 选一个工作区

    在电脑上新建文件夹，把讲义放进去。在 EduWork 点「新会话」，选择这个文件夹。要让它生成文件，将权限设为「工作区内修改」。

  3. 说清楚想要的结果

    在输入框输入 @ 选中讲义，再告诉它要交付什么。例如：

    请根据这份讲义整理一页复习提纲，列出三个核心概念，每个配一个例子。把结果保存为工作区里的「复习提纲.docx」。

  4. 打开成果，继续修改

    展开右侧文件栏，打开「复习提纲.docx」核对内容。要换个例子，直接在同一会话里说“把第二个例子换成日常生活中的场景”，再打开文件查看修改。

下次可以从「应用 → 使用教程」回到这里，或点面板上的「重新播放引导」再看一遍工作台各个位置。
