# EduWork 扩展入口

[English](README_EN.md)

在 DSH 原生左侧“插件”页中增加“EduWork 扩展”页签，供用户查看、启用、停用和配置可选预装包。目录目前以外部智能体为首个接入项；只显示当前安装中实际可用的包。

## 边界

- 入口随产品提供，独立于被管理的包，停用扩展后入口仍在。
- 通过官方 `listBundles` / `setBundleEnabled` 读取和改变状态；兼容检查、权限、配置持久化及热重载由 DSH 负责。界面展示失败和需要重启的结果，不乐观地假定已经运行。
- `lib/catalog.js` 只保存名称、双语介绍、说明链接及首次预装默认值。产品装配必须先取得已发布 npm 包的精确锁；没有锁的源码包不会被装入正式产品。
- `disabledByDefaultBundles` 控制首次预装是否启用，必须是 `optionalBundles` 的子集。用户已有激活记录优先，重启与升级不重置选择。现有可选包的默认行为保持不变。
- 本页不安装外部 CLI、不启动智能体、不管理凭据，也不改变任务权限。

## 插件配置

插件启用后可通过官方 Slot API 向 `eduwork.extensions.config` 注册 keyed 组件，key 为 npm 包名。它使用普通 `renderSlot` 生命周期，停用时由 DSH 撤销组件。插件可以把同一表单注册到官方 `plugins.bundle.config`，供独立 DSH 安装使用；设置页也可复用该表单。

新增目录项时，应先完成包发布和锁定，并验证默认关闭、启停、重启、已有用户偏好及配置组件销毁。此产品界面只在当前 0.2.1 构建流程中启用，不向旧内核分支回填。
