## DSH 0.1.7-rc.2 file references

The candidate build retains the official local-path intake and renders file
reference nodes as cards using the official `FileTypeIcon`, file extension and
size formatters. Optional byte counts come from the selected `File`, without
additional filesystem access. They follow node cloning, undo and reference
projection; references without known size still show their type and full name.
Persisted drafts retain the upstream text-reference format; this adapter does
not add a second draft store or retain selected-file metadata across reloads.

The remove button edits the original Lexical node in one undoable operation and
respects the editor's read-only state. Clipboard text, reference serialization,
directory references, image attachments and submission remain upstream-owned.
Pure reference-decoration rescans merge into history so an asynchronous
highlight refresh cannot consume the undo intended for a file removal.
The small adapter in `scripts/native-file-reference-ui.mjs` requires unique
anchors in the pinned bundle and only affects the existing product derivative.
It can be retired when the upstream reference presentation offers equivalent
cards or an extension slot; it does not modify the published official package.
