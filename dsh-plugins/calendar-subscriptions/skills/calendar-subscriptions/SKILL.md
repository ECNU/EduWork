# 日历订阅

订阅是远程只读来源：插件按周期拉取 ICS 并写入本地日历，事件由来源整体维护，个人日程、笔记和提醒不随订阅变动。本技能与「日历与日程管理」配合：订阅负责让数据进来，查询与个人内容沿用日历工具。

## 建议流程

1. 先用 `calendar_subscriptions` 查看现有订阅及其状态（上次成功时间、最近错误），再决定是否新增或调整。
2. 添加订阅用 `calendar_subscribe`，给出 `http(s)` 地址，可选名称和刷新小时数（默认 24，最小 1）。同一地址重复订阅是更新，不会产生副本。
3. 需要立即更新时用 `calendar_refresh_subscriptions`；不给 `id` 刷新全部启用中的订阅。刷新失败会保留旧数据并报告原因，不要因失败就建议退订重订。
4. 暂停用 `calendar_update_subscription` 传 `enabled:false`（停止刷新并隐藏事件，不删除）；恢复传 `true`。改名、改周期用同一工具。
5. 确认不再需要时用 `calendar_unsubscribe` 退订：该来源事件被清除，个人内容保留，重新订阅同一地址会沿用原编号。

## 边界说明

- 订阅写入的是来源管理的日程（`sync:` 来源），不要用导入或逐条写入工具去改它们；来源数据以远程为准。
- 部分读取失败的订阅按部分快照处理（不删除缺席条目），报告中的 skipped/degraded 应转述给用户。
- 学校课表、机构校历等需要登录的来源由各自的机构数据插件接入，不通过本工具传地址绕过鉴权。
