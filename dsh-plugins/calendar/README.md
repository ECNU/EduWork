# EduWork 日历插件

**简体中文** | [English](README_EN.md)

本机日历与日程管理。首次打开显示整月，切换到周视图时保留当前日期。两种视图共用同一份日程和笔记。选中学校校历后，可打开学年总览并从某个阶段跳到对应月份。当前处于开发阶段。

## 功能

- 支持前后翻页、回到今天，以及在「日历来源」中选择校历和筛选日程。月内同一天的额外日程可点「+N 项」展开。
- 周视图按小时排列，重叠日程并排显示，全天和跨天活动也可查看。点击或拖选空白时段可新建。月视图点击日期空白处即可以当天为日期新建，默认勾选「全天」，可切换到具体时间。地点、备注和重复设置收在「更多选项」中。
- 新建、编辑与确认后删除日程；重复可选不重复、每天、每周、自选星期，并可设结束日期。自选星期还支持隔周。
- 重复日程可单独改期、改地点、取消或撤销改期。打开日程记录页的「出现时间」可查看或恢复已取消的日期。
- 每条日程有一个可编辑的「备注」。导出 ICS 时可勾选「包含我的备注」，默认关闭。「我的笔记」独立保存，改期保留原身份时随之保留。
- 文件选择、拖拽或粘贴 ICS 导入；文件名默认作为日历名称。不同日历分开保存，同一日历的相同编号更新，默认保留此次未列出的日程。只有显式开启移除选项才清理该日历中缺席的记录。
- 选中导入日历后可删除整份日历，需再次确认；其他日历及私人笔记、备注和提醒设置保留。个人默认日历和学校同步日历不能从此入口删除。同步日历显示来源提供的可读名称。
- 导出可复制或下载 ICS。ICS 不包含私人笔记，不能代替完整数据备份。含机构托管来源的文件不能回写学校日历，须由来源提供者更新。
- 个人设置支持整条日程默认值、单次覆盖和恢复默认，包括笔记、私人备注、隐藏、提前或固定时间提醒。隐藏后仍可从「更多」→「日程记录」打开记录页恢复。
- Agent 可读取、新建、修改、删除日程，调整/取消/恢复某一次，读写笔记和个人设置。写操作使用项目既有的会话权限机制。
- 外部来源或 Agent 修改后，已打开的面板会自动刷新；断线后重新订阅变化。

日程和个人设置保存在本机。提前或固定时间提醒到点后进入“提醒”记录；桌面版接入系统通知，浏览器提供应用内提醒，不会启动模型或新建会话。需保持应用运行；重启后补发最近24小时的到点提醒，记录保留30天。系统弹窗受应用通知总开关、前后台状态和系统勿扰设置影响。

公版附带“日历与日程管理”技能，指导查询、调整日程、管理私人内容与批量导入。机构可附加参考资料，首次学校数据初始化由机构插件完成。

## Agent 工具

| 工具 | 用途 |
|---|---|
| `calendar_list_events` | 按日期读取日程，包含来源、备注和笔记所需的原始身份 |
| `calendar_create_event` / `calendar_update_event` | 新建、修改整条日程及备注 |
| `calendar_delete_event` | 删除整条日程 |
| `calendar_occurrence` | 改期、撤销、取消、恢复某一次 |
| `calendar_notes` | 读笔记，也可查询已失联但保留的笔记 |
| `calendar_put_note` / `calendar_remove_note` | 保存、清空整条或某一次的私人笔记 |
| `calendar_read_personal` / `calendar_personal_settings` | 读取个人设置，按字段修改或恢复默认 |
| `calendar_import_source` | 使用稳定编号按来源批量导入或更新 |

操作导入日程时须沿用读取结果的 `source` 和 `uid`。工具返回的文本也携带完整引用；Agent 写笔记与个人设置前会校验目标存在，不能凭空创建失联设置。针对某一次的个人设置须使用读取结果的 `originalStart`，不能用改期后的时间代替；省略它操作整条日程的默认设置。修改整条日程与修改某一次是两个不同操作。

## 机构接入边界

公版提供来源登记、启停与批量写入；机构插件负责授权、取数、转换、定时和登录/重连重试。账号与逻辑来源分别构成稳定身份，来源失败保留旧数据，注销来源会隐藏缓存而不删除笔记。通用教育语义、校历选择及完整课表导入由 [教育校历插件](../../packages/dsh-academic-calendar/README.md) 提供；学校远端接口尚未接入。学校调课需要可识别原来那一次的信息；无法判断时返回未能关联，不猜测。整条重复规则变化后的自动关联暂不支持。接入方式见[来源与提醒接口](../../docs/proposals/calendar/INTEGRATION.md)。

教学周、考试周和假期由 `registerAnnotations` 登记的注解提供方按日期范围给出。周次标注显示在周视图副标题和月视图对应周的周一旁，有色阶段以带日期的区间条显示在月视图的对应周行上方。支持按 `group` 查询选中的注解提供方。视图可以用 `includeOriginalSpan` 请求校历原始日期，提供方可用 `originalFirstDay` 和 `originalLastDay` 保留被裁剪的端点。学年总览读取当前选中的 `academic-calendar` 提供方。提供方异常、超时或格式不符时丢弃该次回答（单个提供方 3 秒上限），不影响事件读取与其他提供方。

学校和导入日程的来源说明只读，导出时保留。个人备注只有主动勾选才随 ICS 导出，笔记和其他个人设置始终留在本机。旧版归属不明的说明和附加信息在个人设置中保留备份。

## 构建与验证

客户端由项目锁定编译链经 `build-client.mjs` / `build-client.ps1` 构建，产品组装沿用统一入口。FullCalendar 随日历客户端打包。日历作为插件装配，React、界面控件与配色由宿主提供。实现与接入说明见[模块提案](../../docs/proposals/calendar/README.md)及[包开发指南](../../docs/PACKAGES.md)。

准备项目 Runtime 后设置 `EDUWORK_TEST_RUNTIME` 指向其 `product/d` 目录，在插件目录执行 `npm test`。真实浏览器面板验证执行 `npm run test:browser`，默认使用本机 Edge；可用 `EDUWORK_BROWSER_CHANNEL` 指定已安装的 Chromium 通道。

浏览器验证挂载真实面板与日历服务，基础 UI 组件使用测试替身；它验证面板交互，不代表完整桌面外壳、真实模型会话或学校接口已经验收。

完整桌面已在隔离数据目录启动后，可将 `EDUWORK_DESKTOP_TEST_CDP` 设为仅本机的调试地址，再执行 `npm run test:desktop`。此检查使用产品实际的 UI 组件，在两种窗口尺寸下填写、保存重复日程，并清理自己创建的数据；请使用专门的验收环境。
