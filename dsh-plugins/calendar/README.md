# EduWork 日历插件

**简体中文** | [English](README_EN.md)

本机日历与日程管理。周视图用于安排每天的时间，月视图用于浏览整月；两种视图共用同一份日程和笔记。当前处于开发阶段。

## 功能

- 空日历直接显示周网格。支持周/月切换、前后翻页、回到今天，以及按日历来源筛选。
- 周视图按小时排列，重叠日程并排显示，全天和跨天活动也可查看。在空白时段拖动或双击可新建；月视图可按日期新建，展开当天的更多日程。
- 新建、编辑与确认后删除日程；重复可选不重复、每天、每周、自选星期，并可设结束日期。自选星期还支持隔周。
- 重复日程可单独改期、改地点、取消或撤销改期；已取消日期可从顶部“日程”菜单进入记录页恢复。
- “备注”属于日程，会写入 ICS；“我的笔记”属于某一次日程，独立保存，不写入 ICS。改期保留原身份时笔记随之保留。
- 文件选择、拖拽或粘贴 ICS 导入；文件名默认作为日历名称。不同日历分开保存，同一日历的相同编号更新，默认保留此次未列出的日程。只有显式开启移除选项才清理该日历中缺席的记录。
- 选中导入日历后可删除整份日历，需再次确认；其他日历及私人笔记、备注和提醒设置保留。个人默认日历和学校同步日历不能从此入口删除。同步日历显示来源提供的可读名称。
- 导出可复制或下载 ICS。ICS 不包含私人笔记，不能代替完整数据备份。
- 个人设置支持整条日程默认值、单次覆盖和恢复默认，包括笔记、私人备注、隐藏、提前或固定时间提醒。隐藏后仍可从“日程”菜单打开记录页恢复。
- Agent 可读取、新建、修改、删除日程，调整/取消/恢复某一次，读写笔记和个人设置。写操作使用项目既有的会话权限机制。
- 外部来源或 Agent 修改后，已打开的面板会自动刷新；断线后重新订阅变化。

日程和个人设置保存在本机。可保存提前提醒或固定时间提醒并计算执行时间；公版尚未接入到点通知。

## Agent 工具

| 工具 | 用途 |
|---|---|
| `calendar_list_events` | 按日期读取日程，包含来源、备注和笔记所需的原始身份 |
| `calendar_create_event` / `calendar_update_event` | 新建、修改整条日程及备注 |
| `calendar_delete_event` | 删除整条日程 |
| `calendar_occurrence` | 改期、撤销、取消、恢复某一次 |
| `calendar_notes` | 读笔记，也可查询已失联但保留的笔记 |
| `calendar_put_note` / `calendar_remove_note` | 保存、清空整条或某一次的私人笔记 |
| `calendar_read_personal` / `calendar_personal_settings` | 读取个人设置，按字段修改或恢复默认 |

操作导入日程时须沿用读取结果的 `source` 和 `uid`。针对某一次的个人设置须使用读取结果的 `originalStart`，不能用改期后的时间代替；省略它操作整条日程的默认设置。修改整条日程与修改某一次是两个不同操作。

## 机构接入边界

公版提供来源登记、启停与批量写入；机构插件负责授权、取数、转换、定时和登录/重连重试。账号与逻辑来源分别构成稳定身份，来源失败保留旧数据，注销来源会隐藏缓存而不删除笔记。真实学校接口及独立的“校历/课表”入口尚未接入。学校调课需要可识别原来那一次的信息；无法判断时返回未能关联，不猜测。整条重复规则变化后的自动关联暂不支持。接入方式见[来源与提醒接口](../../docs/proposals/calendar/INTEGRATION.md)。

来源说明与私人备注分别保存，不会互相覆盖；私人内容不随 ICS 导出。旧版归属不明的备注和附加信息会保留备份，在个人设置中供用户确认。

## 构建与验证

客户端由项目锁定编译链经 `build-client.mjs` / `build-client.ps1` 构建，产品组装沿用统一入口。React 和产品 UI 基础组件由宿主提供；不另维护一条客户端发布构建链。实现与接入说明见[模块提案](../../docs/proposals/calendar/README.md)及[包开发指南](../../docs/PACKAGES.md)。

准备项目 Runtime 后设置 `EDUWORK_TEST_RUNTIME` 指向其 `product/d` 目录，在插件目录执行 `npm test`。真实浏览器面板验证执行 `npm run test:browser`，默认使用本机 Edge；可用 `EDUWORK_BROWSER_CHANNEL` 指定已安装的 Chromium 通道。

浏览器验证挂载真实面板与日历服务，基础 UI 组件使用测试替身；它验证面板交互，不代表完整桌面外壳、真实模型会话或学校接口已经验收。

完整桌面已在隔离数据目录启动后，可将 `EDUWORK_DESKTOP_TEST_CDP` 设为仅本机的调试地址，再执行 `npm run test:desktop`。此检查使用产品实际的 UI 组件，在两种窗口尺寸下填写、保存重复日程，并清理自己创建的数据；请使用专门的验收环境。
