# 官方浏览器适配

**简体中文** | [English](README_EN.md)

当前 DSH 候选产品使用官方 Playwright MCP 操作网页。本适配绑定随桌面包提供的 Chromium，提供按文字读页、一次执行多个动作的 `browser_read` 和 `browser_act`，只在有风险的步骤前确认，并限制危险的本机代码执行。页面工具、跨域导航、JavaScript、会话隔离和进程释放由官方实现负责。

公版搜索继续使用独立 `eduwork-search`：配置 DeepSeek Key 时使用官方搜索，否则使用 Bing/Baidu。迁移浏览器不改变搜索服务或会话模型。

浏览器保留 `eduwork-browser` 插件标识及原启停选择；旧交互实现不再挂载。技能仍叫 `browser`，技能开关控制模型可见的指导，插件开关控制浏览器工具。技能关闭本身不撤销工具权限。

关闭插件会卸载已有浏览器工具；重新启用后，请重启应用再继续已有会话，无需删除历史对话。官方实现只在会话运行实例创建时挂载工具，不会为仍在运行的实例自动补挂。

## 配置

- `executablePath`：可选，只作用于独立浏览器。桌面默认使用 `DSH_MEDIA_BROWSER` 指向的内置 Electron Chromium；独立 Host 未绑定该变量时由官方 MCP 查找浏览器。显式指定但缺失的程序会报错。
- `headless`：默认 `true`，只作用于独立浏览器。需要可见的受管窗口时由用户设置为 `false`，重建会话生效；不支持旧工具按动作切换窗口模式。
- `toolCallTimeoutMs`：默认 120000，允许 1000–300000。

子 Agent、Web 与 CLI 中，每个会话拥有独立浏览器，不共享侧栏或系统浏览器登录态；重启后不保证保留登录。恢复连接后先检查页面，不能自动重复提交操作。此适配不提供远端 SSH 浏览器或电脑操作。

## 读页与操作

`browser_read` 把网页读成文字：用户此刻看得到的内容，加上能用的链接、按钮和输入框，各带一个编号，例如 `[#12 button "搜索"]`。输入框写明已填的内容和网页声明的要求（类型、范围、长度），密码只说明是否已填；图表等画出来的内容标出位置，提示用截图查看。`browser_act` 按这些编号在一次调用里依次输入、点击、选择、按键、滚动、返回或等待，网页换页时提前停下，返回此时的网页；会换页的链接直接打开它的地址。两者经同一个 Playwright MCP 执行，侧栏和独立浏览器都可用。截图不带文件名时图片直接返回给 Agent；带文件名时保存在工作区，结果写明完整路径。

## 确认

浏览器步骤不逐次确认：用户的请求本身就包括打开网页、点链接、填写和翻页。应用只在这些操作前自己确认：在网页里运行脚本、上传或拖放文件、确认网页弹出的对话框、关闭浏览器，以及从别的网站进入本机或内网地址（同一网站里的链接不再确认）。截图等结果带文件名保存到工作区时，按会话的文件权限处理，只读会话才确认。提交申请或报名、发送消息、付款、删除、填写学号手机号等个人信息之前，Agent 用 `browser_act` 的 `confirm` 请用户确认，一件事只问一次，提示列出将执行的每一步；这种确认在 Full Access 下也会出现。`browser_run_code_unsafe` 只能在 Full Access 下执行，其最终拒绝不能被其他普通授权钩子覆盖。网页内容始终视为不可信数据。

## 桌面侧栏

桌面版中，对话自己的 Agent 直接操作该对话右侧侧栏里的浏览器标签页：用户能看到每一步，随时可以停下 Agent 接手，登录、验证码等步骤也在同一页面上由用户完成。

- 已打开的标签页属于用户。Agent 可以读取和操作，确认范围同上；与当前页面无关的浏览会开新标签页。
- Agent 操作的标签页显示蓝色边框和“Agent 正在操作 · 停止”。Agent 这一轮运行期间，该标签页只能看、不能操作，避免双方同时操作；用户点“停止”（与输入框的停止键相同）或等这一轮结束（例如 Agent 请用户登录时）即可接手，之后在对话里让 Agent 继续。侧栏在 Agent 开始操作时展开一次；用户之后收起，Agent 就在收起状态下继续，只有新开标签页时才再次展开。
- Agent 的点击和切换不会带走用户的焦点，例如正在输入的消息或另一个对话里正在用的网页。
- 对话不在电脑屏幕上时（用户在看其他对话，或用手机远程接入），Agent 仍可操作已打开的标签页，新开的网页在后台打开：Agent 照常操作，登录状态与侧栏相同，但用户看不到；Agent 关闭浏览器或退出后，这些页面随之关闭。侧栏标签页里的链接弹出的新窗口仍要等用户回到该对话才会加载。
- 只有本机 Host 进程拿到连接地址；Agent 只能看到本对话的标签页，网页无法借此访问应用窗口、其他对话或 Cookie 存储。
