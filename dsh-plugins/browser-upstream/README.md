# 官方浏览器适配

**简体中文** | [English](README_EN.md)

当前 DSH 候选产品使用官方 Playwright MCP 操作网页。本适配只绑定随桌面包提供的 Chromium、保留公版交互确认，并限制危险的本机代码执行。页面工具、跨域导航、JavaScript、会话隔离和进程释放由官方实现负责。

公版搜索继续使用独立 `eduwork-search`：配置 DeepSeek Key 时使用官方搜索，否则使用 Bing/Baidu。迁移浏览器不改变搜索服务或会话模型。

浏览器保留 `eduwork-browser` 插件标识及原启停选择；旧交互实现不再挂载。技能仍叫 `browser`，技能开关控制模型可见的指导，插件开关控制浏览器工具。技能关闭本身不撤销工具权限。

关闭插件会卸载已有浏览器工具；重新启用后，请重启应用再继续已有会话，无需删除历史对话。官方实现只在会话运行实例创建时挂载工具，不会为仍在运行的实例自动补挂。

## 配置

- `executablePath`：可选。桌面默认使用 `DSH_MEDIA_BROWSER` 指向的内置 Electron Chromium；独立 Host 未绑定该变量时由官方 MCP 查找浏览器。显式指定但缺失的程序会报错。
- `headless`：默认 `true`。需要可见的受管窗口时由用户设置为 `false`，重建会话生效；不支持旧工具按动作切换窗口模式。
- `toolCallTimeoutMs`：默认 120000，允许 1000–300000。

非 Full Access 模式保留网页交互、截图和私网导航确认。私网判定先解析域名：本机、局域网、CGNAT、链路本地等地址（含 IPv4 映射的 IPv6、NAT64、6to4 和尾点、单标签主机名）都按私网处理，解析失败或超时也会询问。`browser_navigate` 和 `browser_tabs` 新建标签页的地址都按此校验。用户确认过的私网来源在本会话内不再询问。工具结果显示页面停在未确认的私网来源时（例如公网页面重定向过去，或域名被重新解析到本机），该结果会被拦下，模型只看到提示；此后读取页面的工具也改为询问，直到页面回到公网或用户确认该地址。`browser_run_code_unsafe` 只能在 Full Access 下执行，其最终拒绝不能被其他普通授权钩子覆盖。网页内容始终视为不可信数据。

每个会话拥有独立浏览器，不共享侧栏或系统浏览器登录态；重启后不保证保留登录。恢复连接后先检查页面，不能自动重复提交操作。此适配不提供远端 SSH 浏览器或电脑操作。
