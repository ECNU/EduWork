# EduWork 使用帮助

EduWork 是单机工作台，项目、会话和偏好保存在本机。先核对当前发行版实际具备的功能，不根据旧产品说明虚构菜单或服务。

- 首次使用：选择工作区，在模型设置中配置兼容服务的地址、模型和 API Key；也可使用发行版配置的企业登录。默认运行凭据引用为 `EDUWORK_API_KEY`，不要索取或在回复中展示 Key。
- 企业与品牌：企业列表来自程序旁 `config/eduwork.jsonc`，设置中的学校/企业服务可打开配置文件；注释和 `config/examples` 提供示例。修改后完全退出再重启。不需要通过界面添加企业。
- 技能：设置的插件页面中打开“技能”，搜索、创建、导入或开关。开关会持久保存。缺少服务与关闭技能是不同状态；以实际目录为准，不建议安装重复功能。
- Studio：从官方侧栏打开，使用报告、导图、测验、闪卡、表格、演示、音频、视频八类成果。没有 Wiki 构建前提。对话和 Studio 共用生成与预览能力。成果下载中只承诺当前界面实际提供的格式。
- 语音：端侧服务与已配置远程服务按可用性出现。模型下载及系统组件是否已就绪应实际检查。
- 更新：设置中检查更新，渠道由配置文件管理。测试绿色包通过发布页面下载，完全退出后替换程序，保留 `data` 和 `config`。不要承诺当前版本尚未验证的自动跨壳迁移。
- 排错：设置中导出诊断摘要；若需要会话执行细节，可由用户主动导出 Session 日志。不要批量读取凭据库或无关会话。报告环境、步骤、实际错误和是否可复现。

机构配额、活跃心跳和校内搜索是可选机构能力，只有相应发行版和服务支持时才说明其入口。通用网页浏览与校内搜索是不同能力。
