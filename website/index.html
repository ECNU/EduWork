01 / THE PROJECT基于 DSH，共建教育场景

在同一基础上，
建设可复用的教育能力。

DSH 提供 Agent 运行时与插件基础。
EduWork 把机构接入、资料创作与教育技能组合起来，
形成可直接使用、也可继续扩展的桌面发行版。

01

持续复用上游

会话、工具、浏览器与文件能力优先跟随 DSH，把精力放在教育工作需要的扩展。

02

公共能力独立维护

机构登录、Studio、记忆等以插件组织，按兼容范围供其他 DSH 应用复用。

03

机构服务按需接入

用配置连接模型，用插件接入业务。共享通用改进，保留各自的服务与品牌。

INSIDE EDUWORK
对话、工具与成果，在同一个工作区。

复用 DSH 的 Agent 能力，围绕本机资料开展任务，预览结果并继续完善。

IDENTITY & MODELS

机构登录与模型接入

@eduwork/dsh-oidc

浏览器单点登录、模型发现与 Token 管理。支持 LiteLLM 原生 OAuth 与实验性 oidc-llm 草案。

MATERIALS TO ARTIFACTS

Knowledge Studio

@eduwork/dsh-knowledge-studio

围绕工作区资料创建报告、演示、测验与闪卡；通过共享成果服务与界面插槽扩展创作能力。

RESEARCH WORKFLOW

文献检索

@eduwork/dsh-literature

检索 DBLP、arXiv 文献，获取 BibTeX 与可用全文。接续社区实现，逐步拓展研究资料来源。

文档与源码 npm ↗
CONTEXT & MEMORY

本地记忆

@eduwork/dsh-memory

管理本地记忆、检索历史对话，让后续任务接得上已有背景。数据与记忆在本机管理。

文档与源码 npm ↗
CONNECTED TOOLS

邮件助手

@eduwork/dsh-mail

通过 IMAP 读取邮件，经授权通过 SMTP 发送，让日常沟通接入同一套工作流程。

文档与源码 npm ↗

03 / INSTITUTIONAL ADOPTION发行版与扩展边界

连接你们的服务，
共享我们的积累。

机构可以从公共发行版出发，连接已有模型平台，追加校内服务插件与专用技能，保留自己的品牌和更新渠道。

只需模型接入时，通过配置即可开始；需要专属业务能力时，再增加对应插件。
