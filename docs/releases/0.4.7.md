EduWork 0.4.7

[中文](#cn-047) | [English](#en-047)

<h2 id="cn-047">中文</h2>

本次包含安全更新，建议所有用户升级。提供 **Windows x64** 与 **macOS arm64** 桌面包，内核保持 **DSH 0.2.1-rc.2**。

- **安全修复**：将随包 Node.js 从 24.18.0 升级至 **24.22.1**，修复上游安全公告中的漏洞。需要更新桌面应用才能获得修复（[#195](https://github.com/ECNU/EduWork/pull/195)，关联 [#194](https://github.com/ECNU/EduWork/issues/194)；[上游安全公告](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)）。
- **通知改进**：统一插件通知通道，托盘、系统提示和桌宠共用通知状态；不同插件使用独立队列，避免批量通知挤占 Agent 提问与授权提醒。同步升级 **Studio 0.6.1** 和 **桌宠 0.1.1**，保持通知发布、撤回与点击处理一致（[#190](https://github.com/ECNU/EduWork/pull/190)）。
- 统一普通启动的加载界面，改善从启动到主界面的过渡（[#188](https://github.com/ECNU/EduWork/pull/188)）。
- 隐藏启动窗口的多余菜单，修正菜单语言，并为新增设置栏目提供不同图标（[#178](https://github.com/ECNU/EduWork/pull/178)、[#179](https://github.com/ECNU/EduWork/pull/179)）。
- 更新独立插件的 DSH 0.2.1 兼容性，统一使用已发布的 npm 插件装配产品（[#181](https://github.com/ECNU/EduWork/pull/181)、[#182](https://github.com/ECNU/EduWork/pull/182)、[#183](https://github.com/ECNU/EduWork/pull/183)）。

本次不包含日历、学校校历或课表功能。

<h2 id="en-047">English</h2>

This release includes security fixes. **All users are encouraged to upgrade.** Desktop packages are available for **Windows x64** and **macOS arm64**, retaining **DSH 0.2.1-rc.2**.

- **Security fixes:** Upgrade bundled Node.js from 24.18.0 to **24.22.1**, addressing vulnerabilities covered by the upstream security advisory. Updating the desktop application is required to receive these fixes ([#195](https://github.com/ECNU/EduWork/pull/195), [#194](https://github.com/ECNU/EduWork/issues/194); [upstream advisory](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)).
- **Notifications:** Unify plugin notifications across the tray, system alerts and desktop pet. Separate plugin queues prevent notification bursts from displacing Agent questions and approval requests. Upgrade **Studio to 0.6.1** and the **desktop pet to 0.1.1** together to keep publishing, withdrawal and click handling consistent ([#190](https://github.com/ECNU/EduWork/pull/190)).
- Unify the loading screen for ordinary launches and improve the transition to the main window ([#188](https://github.com/ECNU/EduWork/pull/188)).
- Hide unnecessary startup-window menus, fix menu language, and give additional settings sections distinct icons ([#178](https://github.com/ECNU/EduWork/pull/178), [#179](https://github.com/ECNU/EduWork/pull/179)).
- Improve standalone plugin compatibility with DSH 0.2.1 and assemble the product from published npm plugins ([#181](https://github.com/ECNU/EduWork/pull/181), [#182](https://github.com/ECNU/EduWork/pull/182), [#183](https://github.com/ECNU/EduWork/pull/183)).

Calendar, school calendar and timetable features are not included in this release.
