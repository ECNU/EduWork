EduWork 0.4.4

[中文](#cn-044) | [English](#en-044)

<h2 id="cn-044">中文</h2>

基于 **DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 新增可选桌面宠物，内置红/蓝“小页”、“大肥鱼”和“小花狮”。与任务和通知状态联动，支持切换形象、拖拽、收边和空闲打盹；默认关闭，可在“设置 → 桌面宠物”中开启（[#149](https://github.com/ECNU/EduWork/pull/149)）。
- Office 技能和 Studio 文档处理复用官方工作流，支持旧 DOC、XLS、PPT 的读取与转换，统一 PDF 导出和表格公式重算。旧 DOC 编辑前转换为 DOCX，保留原文件（[#157](https://github.com/ECNU/EduWork/pull/157)）。
- Office 与常见文件预览更多复用官方能力，Studio 可直接预览实际源文件；改善自动适应窗口时的反复缩放和闪动（[#156](https://github.com/ECNU/EduWork/pull/156)，结合 [#155](https://github.com/ECNU/EduWork/pull/155) 的修复）。
- 精简随包运行时、未使用的依赖和语言资源，复用 Electron 自带浏览器，减少安装包与解压后的空间占用（[#136](https://github.com/ECNU/EduWork/pull/136)、[#141](https://github.com/ECNU/EduWork/pull/141)、[#142](https://github.com/ECNU/EduWork/pull/142)）。
- 增加 Windows 文件级增量更新与 macOS Sparkle 增量更新，保留完整包回退。**Windows 从 0.4.3 升级到本版仍使用完整包，安装本版后，后续升级才可使用新的增量能力**（[#144](https://github.com/ECNU/EduWork/pull/144)、[#145](https://github.com/ECNU/EduWork/pull/145)）。
- macOS 检查、下载和安装更新统一到应用内面板，支持后台下载；有任务运行时，退出或立即更新会先确认，避免直接中断任务（[#110](https://github.com/ECNU/EduWork/pull/110)、[#130](https://github.com/ECNU/EduWork/pull/130)）。
- 改善 Windows 启动与工作区沙箱权限处理：已能正常运行的安装不再因权限修复被拒而中止启动；实际遇到可修复的工作区权限故障时，再提供有针对性的修复提示（[#139](https://github.com/ECNU/EduWork/pull/139)、[#148](https://github.com/ECNU/EduWork/pull/148)、[#150](https://github.com/ECNU/EduWork/pull/150)）。
- 修正后台子代理和目标模式的完成提醒时机，避免任务尚未结束就提示完成，并补齐目标受阻后的提醒；加快宿主完成清理后的退出（[#158](https://github.com/ECNU/EduWork/pull/158)、[#108](https://github.com/ECNU/EduWork/pull/108)）。
- 内置视频模板渲染不再向安装目录写入缓存，改善只读安装目录下的使用；渲染服务仅监听本机地址（[#138](https://github.com/ECNU/EduWork/pull/138)、[#143](https://github.com/ECNU/EduWork/pull/143)）。

感谢 [JunieXD](https://github.com/JunieXD)、[wf0229](https://github.com/wf0229)、[SUGE2016](https://github.com/SUGE2016)、[royhang](https://github.com/royhang)、[xhan51](https://github.com/xhan51)、[freedomkk-qfeng](https://github.com/freedomkk-qfeng) 的贡献，以及 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上游团队。感谢 xhan51 提供的早期小花狮原型与素材整理，以及社区桌宠项目的参考实现。

<h2 id="en-044">English</h2>

Based on **DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Add an optional desktop pet with red and blue Page, Dafeiyu, and ECNU Huashi appearances. Pets reflect task and notification states, support dragging, edge docking, appearance switching, and idle sleep. Disabled by default; enable it in Settings → Desktop Pet ([#149](https://github.com/ECNU/EduWork/pull/149)).
- Reuse official Office workflows in skills and Studio, adding legacy DOC, XLS, and PPT reading and conversion, shared PDF export, and spreadsheet formula recalculation. Convert legacy DOC files to DOCX before editing while preserving the originals ([#157](https://github.com/ECNU/EduWork/pull/157)).
- Reuse official previews for Office and common file types, and preview actual Studio source files. Improve repeated resizing and flicker when fitting documents to the window ([#156](https://github.com/ECNU/EduWork/pull/156), incorporating fixes from [#155](https://github.com/ECNU/EduWork/pull/155)).
- Trim bundled runtime files, unused dependencies, and language resources, and reuse Electron's browser to reduce download and installed sizes ([#136](https://github.com/ECNU/EduWork/pull/136), [#141](https://github.com/ECNU/EduWork/pull/141), [#142](https://github.com/ECNU/EduWork/pull/142)).
- Add file-level delta updates on Windows and Sparkle delta updates on macOS, with full-package fallback. **Windows upgrades from 0.4.3 to this release still use the full package; subsequent upgrades can use the new delta capability after this version is installed** ([#144](https://github.com/ECNU/EduWork/pull/144), [#145](https://github.com/ECNU/EduWork/pull/145)).
- Bring macOS update checks, downloads, and installation into the in-app update panel, with background downloading. Quitting or installing immediately asks for confirmation when tasks are running ([#110](https://github.com/ECNU/EduWork/pull/110), [#130](https://github.com/ECNU/EduWork/pull/130)).
- Improve Windows startup and workspace sandbox permissions. An otherwise usable installation no longer stops because a permission repair is denied; targeted repair is offered after an actual, repairable workspace permission failure ([#139](https://github.com/ECNU/EduWork/pull/139), [#148](https://github.com/ECNU/EduWork/pull/148), [#150](https://github.com/ECNU/EduWork/pull/150)).
- Correct completion notifications for background subagents and goal mode, avoiding premature completion alerts and reporting blocked goals. Exit promptly after host cleanup finishes ([#158](https://github.com/ECNU/EduWork/pull/158), [#108](https://github.com/ECNU/EduWork/pull/108)).
- Keep built-in video rendering caches outside the installation directory, improving operation in read-only installations. Bind the rendering service to the local machine only ([#138](https://github.com/ECNU/EduWork/pull/138), [#143](https://github.com/ECNU/EduWork/pull/143)).
