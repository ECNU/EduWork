EduWork 0.4.6

[中文](#cn-046) | [English](#en-046)

<h2 id="cn-046">中文</h2>

内核升级至 **DSH 0.2.1-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 网页操作改用 DSH 官方浏览器与 Playwright MCP，可处理需要 JavaScript 或跨站跳转的页面；保留原有浏览器启停选择，网页交互继续遵循工作区授权（[#173](https://github.com/ECNU/EduWork/pull/173)）。
- 接入新版搜索设置，切换关闭 DeepSeek Search/Fetch API 后恢复 EduWork 的默认搜索策略，保留无 Key 搜索能力（[#173](https://github.com/ECNU/EduWork/pull/173)）。
- 恢复官方可选语音输入，可在插件页启用并按需准备识别模型；支持启用官方开发者工具，查看会话数据并辅助排查问题（[#173](https://github.com/ECNU/EduWork/pull/173)）。
- Office 技能适配新版官方处理流程，按任务加载文档、表格和演示文稿的操作指导；继续复用官方 LibreOffice Kit 完成转换、导出和公式重算（[#173](https://github.com/ECNU/EduWork/pull/173)）。
- 文献插件更新至 `@eduwork/dsh-literature@0.1.3`，修复新版内核下 PDF 链接解析的兼容问题（[#174](https://github.com/ECNU/EduWork/pull/174)）。
- 改善旧会话导入和自动化任务迁移，保留已有任务与自定义预设；修正切换工作目录后的邮件附件、图片编辑和音频文件读取，并完善机构模型接口兼容（[#173](https://github.com/ECNU/EduWork/pull/173)）。

语音输入默认关闭。浏览器插件关闭再开启后，请重启应用再继续已有会话，无需删除历史。

<h2 id="en-046">English</h2>

Upgraded to **DSH 0.2.1-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Use the official DSH browser and Playwright MCP for web interaction, including pages that require JavaScript or cross-site navigation. Preserve the browser's enabled/disabled state and apply workspace permissions to interactions ([#173](https://github.com/ECNU/EduWork/pull/173)).
- Integrate the updated search settings. Turning off the DeepSeek Search/Fetch API restores EduWork's default search strategy, including search without an API key ([#173](https://github.com/ECNU/EduWork/pull/173)).
- Restore optional upstream voice input, which can be enabled in Plugins with its recognition model prepared on demand. Optional upstream Developer Tools provide session inspection and troubleshooting ([#173](https://github.com/ECNU/EduWork/pull/173)).
- Adapt Office skills to the updated official workflow, loading task-specific guidance for documents, spreadsheets, and presentations. Continue using the official LibreOffice Kit for conversion, export, and formula recalculation ([#173](https://github.com/ECNU/EduWork/pull/173)).
- Update the literature plugin to `@eduwork/dsh-literature@0.1.3`, fixing PDF-link extraction compatibility with the new runtime ([#174](https://github.com/ECNU/EduWork/pull/174)).
- Improve historical conversation imports and scheduled-task migration while preserving existing tasks and custom presets. Fix mail attachment, image-editing, and audio input paths after working-directory changes, and improve institutional model adapter compatibility ([#173](https://github.com/ECNU/EduWork/pull/173)).

Voice input is disabled by default. After disabling and re-enabling the browser plugin, restart the app to continue an existing conversation; its history does not need to be deleted.
