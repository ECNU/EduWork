EduWork 0.4.3

[中文](#cn-043) | [English](#en-043)

<h2 id="cn-043">中文</h2>

基于 **DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 修复部分 Windows 电脑安装后无法启动的问题，补齐 Electron 沙箱子进程读取程序文件所需的权限；改善安装目录替换时的重试和错误提示（[#132](https://github.com/ECNU/EduWork/pull/132)）。
- 改善 macOS 从 Finder 或 Dock 启动后的 Git SSH 身份读取，支持复用系统已有的 SSH agent（[#42](https://github.com/ECNU/EduWork/pull/42)、[#112](https://github.com/ECNU/EduWork/pull/112)）。
- 改善 macOS 文件夹选择体验，避免重复弹窗，并正确处理窗口关闭与退出（[#125](https://github.com/ECNU/EduWork/pull/125)）。
- 修复升级内核后，旧发行配置的版本限制阻止新配置生效的问题（[#107](https://github.com/ECNU/EduWork/pull/107)）。
- 完善机构定制配置的合并，保留内置插件的默认设置和机构自定义技能；自建发行版不再误用 EduWork 的更新清单（[#91](https://github.com/ECNU/EduWork/pull/91)、[#115](https://github.com/ECNU/EduWork/pull/115)、[#90](https://github.com/ECNU/EduWork/pull/90)）。
- 改善启动进度条动画，修正 Windows 更新器步骤指示线的对齐（[#129](https://github.com/ECNU/EduWork/pull/129)、[#111](https://github.com/ECNU/EduWork/pull/111)）。

感谢 [dbbDylan](https://github.com/dbbDylan)、[JunieXD](https://github.com/JunieXD)、[wf0229](https://github.com/wf0229)、[SUGE2016](https://github.com/SUGE2016)、[sun-timer](https://github.com/sun-timer)、[freedomkk-qfeng](https://github.com/freedomkk-qfeng) 的贡献，以及 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上游团队。

<h2 id="en-043">English</h2>

Based on **DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Fix startup failures on some Windows computers by restoring the permissions Electron sandboxed processes need to read application files. Improve retries and error messages when replacing the installation directory ([#132](https://github.com/ECNU/EduWork/pull/132)).
- Improve Git SSH authentication when launching from Finder or the Dock on macOS, reusing an existing system SSH agent ([#42](https://github.com/ECNU/EduWork/pull/42), [#112](https://github.com/ECNU/EduWork/pull/112)).
- Improve folder selection on macOS, preventing duplicate dialogs and handling window closure and application exit correctly ([#125](https://github.com/ECNU/EduWork/pull/125)).
- Fix older distribution configuration requirements blocking a newer configuration after a kernel upgrade ([#107](https://github.com/ECNU/EduWork/pull/107)).
- Preserve bundled plugin defaults and institution-specific skills when merging distribution settings. Custom distributions no longer incorrectly use EduWork update manifests ([#91](https://github.com/ECNU/EduWork/pull/91), [#115](https://github.com/ECNU/EduWork/pull/115), [#90](https://github.com/ECNU/EduWork/pull/90)).
- Improve the startup progress animation and fix step connector alignment in the Windows updater ([#129](https://github.com/ECNU/EduWork/pull/129), [#111](https://github.com/ECNU/EduWork/pull/111)).

Thanks to [dbbDylan](https://github.com/dbbDylan), [JunieXD](https://github.com/JunieXD), [wf0229](https://github.com/wf0229), [SUGE2016](https://github.com/SUGE2016), [sun-timer](https://github.com/sun-timer), [freedomkk-qfeng](https://github.com/freedomkk-qfeng), and the upstream [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) team.
