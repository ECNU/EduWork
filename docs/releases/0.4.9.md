EduWork 0.4.9

[中文](#cn-049) | [English](#en-049)

<h2 id="cn-049">中文</h2>

本次为安全更新，建议使用邮件助手的用户尽快升级。提供 **Windows x64**、**macOS Apple Silicon（arm64）** 与 **macOS Intel（x64）** 桌面包。

- **邮件安全修复**：更新邮件助手内嵌的 Nodemailer / Mailparser，修复读取特制邮件地址时可能长时间无响应的拒绝服务问题，并更新相关间接依赖。邮件插件升级为 **@eduwork/dsh-mail 0.2.3**（[#223](https://github.com/ECNU/EduWork/pull/223)）。问题由中国科大词元工坊反馈。

<h2 id="en-049">English</h2>

This security update is recommended for users of the mail assistant. Desktop packages are available for **Windows x64**, **macOS Apple Silicon (arm64)** and **macOS Intel (x64)**.

- **Mail security fix:** Update the Nodemailer / Mailparser code embedded in the mail assistant to fix denial of service caused by crafted email addresses, along with related transitive dependencies. Upgrade the plugin to **@eduwork/dsh-mail 0.2.3** ([#223](https://github.com/ECNU/EduWork/pull/223)). Reported by 中国科大词元工坊 (USTC).
