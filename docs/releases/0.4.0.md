EduWork 0.4.0

[中文](#cn-040) | [English](#en-040)

<h2 id="cn-040">中文</h2>

EduWork 0.4.0 是教育发行版的首个 stable 版本，基于 **DSH 0.2.0-rc.2**。本次汇总 0.3.6 开发周期及 0.4.0 Alpha 阶段的改进，提供 **Windows x64** 和 **macOS arm64** 桌面包。

### ✨ 内核、插件与技能

- 内核从 DSH 0.1.5 经 0.1.7 升级至 0.2.0-rc.2，沿用官方桌面与插件能力，保留 EduWork 的教育插件与桌面集成。
- 插件安装统一使用官方管理器，随包提供 Node 和 pnpm，移除旧社区安装入口；用户插件和启停状态可在重启后保留。
- 接入官方自动化任务插件，可在插件页面按需启用。继承上游的模型搜索、计划审阅、PowerShell 和界面改进；完整内核变更见 [DSH Releases](https://github.com/deepseek-ai/deepseek-harness/releases)。
- 「技能」与「插件」成为并列的侧栏入口，支持内置、个人与项目技能管理；修复切换会话后项目技能发现的问题。
- 文献检索由 EduWork 接续维护为 **`@eduwork/dsh-literature`**，保留 DBLP、arXiv、BibTeX 和可用全文提取能力，适配官方后台任务。Fork 自 [SihanLv/dsh-literature](https://github.com/SihanLv/dsh-literature)。
- 配置与插件按接口兼容范围声明支持的版本，避免兼容的内核小版本升级被不必要的精确版本限制阻断。

### 🐛 对话、创作与权限

- Office、生图、语音、转写及固定模板音视频工具复用已有工作区写入权限，减少重复确认；继续检查目标路径、只读权限和覆盖限制。
- 补齐 Studio 音视频模板及创作技能共享参考文件，修复技能读取规范和媒体生成时的文件缺失问题（[#61](https://github.com/ECNU/EduWork/pull/61)、[#74](https://github.com/ECNU/EduWork/pull/74)）。
- 对话与 Studio 共用的系统语音合成新增 macOS 支持，可使用本机已安装音色生成 WAV。
- 恢复本地附件卡片的文件类型图标、文件名、大小、移除和撤销，保留官方图片上传与消息发送能力。
- 修复内置网页受 iframe 限制无法打开的问题；改善 Agent 浏览器的会话隔离、标签恢复和取消排队。
- 修复旧会话导入缺失历史子会话信息及系统路径别名的问题；改善历史会话预览、本地记忆接入、会话切换后的 Studio 显示和配置刷新后的会话标题。
- 完善子代理数量与模型请求并发的配置入口，保留用户已经保存的设置。

### 🔐 开放接入、配置与隐私

- 统一机构模型的 Token 授权，支持 **oidc-llm 开放协议草案**与 **LiteLLM 原生 OAuth**。登录后发现获授权模型，改善提前刷新、并发刷新和重新登录恢复；支持定制机构登录文案。
- 按用途注册模型：只有 LLM 出现在对话选择器中；可读图的 LLM 仍属于聊天模型，向量、重排、生图与 TTS 模型分别处理。
- 统一生效配置入口，改善写入失败重试、目录搬迁和旧配置迁移；配置更新保留用户修改。
- 为机构发行提供可选的签名配置与 Skills 独立更新、首次下载和离线导入；继续校验签名、哈希及实际兼容性。公版不默认下载学校配置。
- 通过官方配置覆盖机制关闭官方产品统计、会话日志及插件清单上报，并隐藏反馈提交入口。

### 🖥️ 桌面、安装与更新

- 新增任务通知和托盘待处理菜单，以及包含组件版本与项目链接的「关于」页；改善深色设置页、主题图标和预设卡片顺序。
- macOS 恢复复制粘贴等原生快捷键、Dock 点击恢复窗口；优化 Retina 菜单栏图标、Dock 配色，复用官方登录 Shell 环境读取。
- macOS 提供带拖拽指引的 DMG 安装窗口，支持确认安装、替换与取消，并安全处理本次自动安装的源镜像（[#44](https://github.com/ECNU/EduWork/pull/44)、[#51](https://github.com/ECNU/EduWork/pull/51)）。
- Windows 提供 `EduWork-0.4.0-windows-x64-setup.zip` 安装包，缓解资源管理器解压深层依赖时的路径过长问题；保留原始 ZIP 供直接解压及自动更新使用。
- Windows 更新器明确使用当前用户权限运行，改善更新进度、失败原因和恢复指引。
- 0.4.0 默认切至稳定更新渠道，保留用户主动选择的开发渠道及自定义更新源；Alpha 中关闭的更新按迁移提示选择启用。
- 完善中英文使用、配置与机构接入说明。

<h2 id="en-040">English</h2>

EduWork 0.4.0 is the education distribution's first **stable-channel release**, based on **DSH 0.2.0-rc.2**. It consolidates improvements from the 0.3.6 development cycle and the 0.4.0 Alpha series, with desktop packages for **Windows x64** and **macOS arm64**.

### ✨ Core, Plugins and Skills

- Upgrade the core from DSH 0.1.5 through 0.1.7 to 0.2.0-rc.2. Reuse upstream desktop and plugin capabilities while retaining EduWork's education plugins and desktop integration.
- Use the official plugin manager with bundled Node and pnpm, replacing the legacy community installation entry. Preserve user plugins and their enabled state across restarts.
- Include the official automation plugin, available to enable from the plugin page. Inherit upstream model search, plan review, PowerShell and UI improvements; see [DSH Releases](https://github.com/deepseek-ai/deepseek-harness/releases) for the full core changelog.
- Place Skills alongside Plugins in the sidebar, with bundled, personal and project skill management. Fix project skill discovery after switching conversations.
- Continue maintaining literature search as **`@eduwork/dsh-literature`**, preserving DBLP, arXiv, BibTeX and available full-text extraction, with integration into official background jobs. Forked from [SihanLv/dsh-literature](https://github.com/SihanLv/dsh-literature).
- Declare configuration and plugin compatibility using interface version ranges, avoiding unnecessary exact-version restrictions on compatible core updates.

### 🐛 Conversations, Creation and Permissions

- Reuse existing workspace write permissions for Office, image generation, speech, transcription and fixed-template audio/video tools, reducing repeated prompts while retaining path, read-only and overwrite checks.
- Include missing Studio media templates and shared skill references, fixing missing-file errors during instruction loading and media generation ([#61](https://github.com/ECNU/EduWork/pull/61), [#74](https://github.com/ECNU/EduWork/pull/74)).
- Add macOS system speech synthesis to the service shared by conversations and Studio, generating WAV audio with installed voices.
- Restore file-type icons, names, sizes, removal and undo for local attachment cards while preserving official image uploads and message delivery.
- Fix embedded pages blocked by iframe restrictions; improve session isolation, tab recovery and cancellation of queued Agent browser operations.
- Fix historical child-session information and system path aliases in legacy conversation imports. Improve saved-conversation previews, local memory integration, Studio visibility after switching conversations, and conversation titles after configuration refreshes.
- Expose configurable subagent limits and model-request concurrency while preserving saved user preferences.

### 🔐 Open Integration, Configuration and Privacy

- Unify token-based institution model access through the **oidc-llm draft protocol** and **LiteLLM native OAuth**. Discover authorized models after login, improve proactive and concurrent token refresh and re-login recovery, and support custom login text.
- Register models by purpose. Only LLMs appear in the conversation selector; vision-capable LLMs remain chat models, while embedding, reranking, image-generation and TTS models are handled separately.
- Unify the active configuration entry point, improve recovery from write failures, directory moves and legacy configuration migration, and preserve user edits during configuration updates.
- Offer optional signed configuration and Skills updates, first-launch downloads and offline import for institution distributions, with signature, hash and compatibility validation. The public edition does not download school configuration by default.
- Disable official product analytics, conversation-log and plugin-inventory uploads through upstream configuration overrides, and hide official feedback submission controls.

### 🖥️ Desktop, Installation and Updates

- Add task notifications, a tray menu for pending items, and an About page with component versions and project links. Improve dark-mode settings, theme icons and preset card ordering.
- Restore native macOS editing shortcuts and window reopening from the Dock. Improve Retina menu-bar icons and Dock colors, and reuse upstream login-shell environment loading.
- Provide a styled macOS DMG installation window with drag-to-install guidance, installation/replacement confirmation and cancellation, and safe handling of the source image used for automatic installation ([#44](https://github.com/ECNU/EduWork/pull/44), [#51](https://github.com/ECNU/EduWork/pull/51)).
- Provide `EduWork-0.4.0-windows-x64-setup.zip` to mitigate long-path extraction failures in Windows Explorer. Keep the original ZIP for direct extraction and automatic updates.
- Run the Windows updater explicitly with the current user's privileges, and improve update progress, failure explanations and recovery guidance.
- Version 0.4.0 defaults to the stable update channel while preserving explicitly selected development channels and custom update sources. Updates disabled in Alpha can be enabled through the migration prompt.
- Improve Chinese and English usage, configuration and institution integration documentation.
