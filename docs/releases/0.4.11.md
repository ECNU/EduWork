EduWork 0.4.11

[中文](#cn-0411) | [English](#en-0411)

<h2 id="cn-0411">中文</h2>

本次提供 **Windows x64**、**macOS Apple Silicon（arm64）** 与 **macOS Intel（x64）** 桌面包，内核升级至 **DSH 0.2.2-rc.1**。

- **按需启停插件**：在左侧“插件 → EduWork 扩展”中，分别管理批注、侧聊、文献检索、邮件、远程访问和外部智能体。停用保留配置和数据，重启与升级后保留用户选择；发行版可设置首次启用默认值（[#271](https://github.com/ECNU/EduWork/pull/271)）。
- **外部智能体**：连接本机 Codex、Cursor Agent CLI 或其他 ACP 智能体，在对话中委派任务。提供安装发现、连接检查与启停配置，预装后默认关闭；启用插件后，按所用智能体完成登录并配置连接（[#268](https://github.com/ECNU/EduWork/pull/268)、[#271](https://github.com/ECNU/EduWork/pull/271)）。
- **对话中的侧栏浏览器**：Agent 可以直接操作当前对话的侧栏标签页，查看页面、点击、填写和执行浏览器任务，沿用既有权限与审批机制（[#250](https://github.com/ECNU/EduWork/pull/250)）。
- **原生界面与批注**：复用新版 DSH 的文本引用、设置导航图标、文件保存与拖出、启动诊断；批注进一步复用官方选区与浮层能力，保留逐段评论、编号和编辑。设置入口、托盘和软件更新状态接入官方界面，更新下载、差分与安装仍沿用现有机制（[#261](https://github.com/ECNU/EduWork/pull/261)、[#265](https://github.com/ECNU/EduWork/pull/265)、[#272](https://github.com/ECNU/EduWork/pull/272)、[#275](https://github.com/ECNU/EduWork/pull/275)、[#276](https://github.com/ECNU/EduWork/pull/276)）。
- **文献与决策工具修复**：修复部分 arXiv 论文以单个压缩 TeX 文件提供源码时的全文提取，无法取得有效文本时使用后续回退方式；改进发行版决策服务配置兼容性（[#274](https://github.com/ECNU/EduWork/pull/274)、[#269](https://github.com/ECNU/EduWork/pull/269)）。
- **新桌宠形象**：新增花狮娘，作者 **Emily**，素材采用 **CC BY-SA 4.0**；改编说明与许可随插件提供（[#254](https://github.com/ECNU/EduWork/pull/254)、[#270](https://github.com/ECNU/EduWork/pull/270)）。

<h2 id="en-0411">English</h2>

Desktop packages are available for **Windows x64**, **macOS Apple Silicon (arm64)** and **macOS Intel (x64)**, with **DSH 0.2.2-rc.1**.

- **Optional plugin controls:** Manage annotations, side chat, literature search, mail, remote access and external agents individually under Plugins → EduWork extensions. Disabling preserves configuration and data. User choices survive restarts and upgrades, while distributions can set first-install defaults ([#271](https://github.com/ECNU/EduWork/pull/271)).
- **External agents:** Connect local Codex, Cursor Agent CLI or other ACP agents and delegate tasks from a conversation. Discover installations, check connections and manage activation. The bundled plugin starts disabled; enable it, sign in through the chosen agent and configure its connection ([#268](https://github.com/ECNU/EduWork/pull/268), [#271](https://github.com/ECNU/EduWork/pull/271)).
- **Conversation sidebar browser:** Let the Agent operate the current conversation's sidebar tabs to inspect pages, click, fill forms and perform browser tasks, using the existing permission and approval mechanisms ([#250](https://github.com/ECNU/EduWork/pull/250)).
- **Native UI and annotations:** Use upstream text quotes, settings icons, file saving and dragging, and startup diagnostics. Annotations reuse more of the official selection and popup APIs while retaining comments, numbering and editing. Settings, tray actions and update status use upstream UI; update downloads, deltas and installation retain the existing implementation ([#261](https://github.com/ECNU/EduWork/pull/261), [#265](https://github.com/ECNU/EduWork/pull/265), [#272](https://github.com/ECNU/EduWork/pull/272), [#275](https://github.com/ECNU/EduWork/pull/275), [#276](https://github.com/ECNU/EduWork/pull/276)).
- **Literature and decision-tool fixes:** Extract arXiv sources delivered as a single compressed TeX file and fall back when no usable source text is available. Improve compatibility with decision-service configuration supplied by distributions ([#274](https://github.com/ECNU/EduWork/pull/274), [#269](https://github.com/ECNU/EduWork/pull/269)).
- **New desktop pet:** Add Huashi Girl, created by **Emily**, with artwork licensed under **CC BY-SA 4.0**. Attribution, adaptation details and licensing are included with the plugin ([#254](https://github.com/ECNU/EduWork/pull/254), [#270](https://github.com/ECNU/EduWork/pull/270)).
