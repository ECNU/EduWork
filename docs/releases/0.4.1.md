EduWork 0.4.1

[中文](#cn-041) | [English](#en-041)

<h2 id="cn-041">中文</h2>

基于 **DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 图像创作新增编辑能力：兼容标准 `/images/edits`，可提交原图及可选遮罩；保留原图，编辑结果另存，复用已有工作区写入权限。服务商通过配置声明是否支持编辑。
- 修复 macOS 手动拖拽安装后无法清理源 DMG 的问题；只在唯一匹配且签名一致时正常推出安装卷、将源镜像移入废纸篓（[#83](https://github.com/ECNU/EduWork/pull/83)，感谢 [JJasonSun](https://github.com/JJasonSun)）。
- 机构登录支持显式申请额外服务权限，供机构发行接入搜索等服务；未配置时沿用原有登录行为（[#84](https://github.com/ECNU/EduWork/pull/84)）。

感谢 [JJasonSun](https://github.com/JJasonSun)、[freedomkk-qfeng](https://github.com/freedomkk-qfeng) 的贡献，以及 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上游团队。

<h2 id="en-041">English</h2>

Based on **DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Image creation now supports editing through the standard `/images/edits` endpoint, including source images and an optional mask. Originals are preserved, results are saved separately, and existing workspace write permission is reused. Providers explicitly declare editing support in configuration.
- Fix source DMG cleanup after manual drag-and-drop installation on macOS. Cleanup only ejects and moves a uniquely matched, signature-verified source image to Trash ([#83](https://github.com/ECNU/EduWork/pull/83), thanks to [JJasonSun](https://github.com/JJasonSun)).
- Institution sign-in can explicitly request additional service permissions for integrations such as search. Unconfigured clients retain their existing sign-in behavior ([#84](https://github.com/ECNU/EduWork/pull/84)).

Thanks to [JJasonSun](https://github.com/JJasonSun), [freedomkk-qfeng](https://github.com/freedomkk-qfeng), and the upstream [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) team.
