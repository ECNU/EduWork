EduWork 0.4.5

[中文](#cn-045) | [English](#en-045)

<h2 id="cn-045">中文</h2>

基于 **DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 在设置中增加软件更新开关。公测版和开发版均默认开启，由用户选择是否启用，并记住关闭状态；更新渠道可单独选择，关闭软件更新不影响发行配置与技能更新（[#166](https://github.com/ECNU/EduWork/pull/166)）。
- 开发版保留完整更新能力，可继续升级到后续公测版；保留已有更新源和用户选择，使用与公测版一致的应用身份与数据目录，方便后续升级（[#164](https://github.com/ECNU/EduWork/pull/164)、[#166](https://github.com/ECNU/EduWork/pull/166)）。
- 修复通过 PowerShell 从源码构建 macOS 应用时，编译参数被拆分导致打包失败的问题（[#165](https://github.com/ECNU/EduWork/pull/165)）。

<h2 id="en-045">English</h2>

Based on **DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Add a software update switch in Settings. Stable-channel and development releases enable updates by default, let users turn them off, and remember that choice. The update channel remains a separate choice; disabling software updates does not disable distribution configuration or skill updates ([#166](https://github.com/ECNU/EduWork/pull/166)).
- Retain update support in development releases so they can upgrade to later stable-channel releases. Preserve existing update sources and user choices, and use the same application identity and data directory as stable-channel releases to support subsequent upgrades ([#164](https://github.com/ECNU/EduWork/pull/164), [#166](https://github.com/ECNU/EduWork/pull/166)).
- Fix a split compiler argument that could prevent macOS source builds from completing when run through PowerShell ([#165](https://github.com/ECNU/EduWork/pull/165)).
