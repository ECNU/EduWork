EduWork 0.4.8

[中文](#cn-048) | [English](#en-048)

<h2 id="cn-048">中文</h2>

本次提供 **Windows x64**、**macOS Apple Silicon（arm64）** 与新增的 **macOS Intel（x64）** 桌面包，内核升级至 **DSH 0.2.1-rc.3**。

- **选段批注**：选中回复中的文字后添加批注，多条批注可以一起发送；支持来源编号、编辑管理和已发送批注展示，沿用原生输入框、引用和草稿机制。以独立 npm 插件预装（[#154](https://github.com/ECNU/EduWork/pull/154)、[#200](https://github.com/ECNU/EduWork/pull/200)）。
- **远程访问**：从手机或其他电脑的浏览器连接本机 EduWork，继续会话并处理授权。支持本机配对确认、端到端加密中继和设备撤销；远控默认关闭，需要自行部署中继并配置接入地址与 Key。插件与中继由同一个 npm 包提供，附[中英文部署指南](https://github.com/ECNU/EduWork/tree/main/packages/dsh-remote-access/docs)（[#192](https://github.com/ECNU/EduWork/pull/192)、[#205](https://github.com/ECNU/EduWork/pull/205)、[#207](https://github.com/ECNU/EduWork/pull/207)、[#216](https://github.com/ECNU/EduWork/pull/216)）。
- **Windows 安装与升级**：改进安装引导、快捷方式和完成后的启动选项；确认覆盖安装时保留用户数据，并在失败时回滚。修复差分升级后第一次启动可能白屏、重新打开才能恢复的问题（[#147](https://github.com/ECNU/EduWork/pull/147)、[#211](https://github.com/ECNU/EduWork/pull/211)）。
- **启动与内核**：升级 DSH 0.2.1-rc.3，接入官方菜单、窗口和技能事件及草稿恢复；保留用户的预设和插件启停选择。启动加载页增加品牌 Logo（[#213](https://github.com/ECNU/EduWork/pull/213)、[#214](https://github.com/ECNU/EduWork/pull/214)、[#215](https://github.com/ECNU/EduWork/pull/215)）。
- **插件体验**：审批提示随中英文界面切换；延后加载邮件协议库、PDF 引擎与搜索浏览器库，减少启动阶段的加载工作。更新邮件、文献和 OIDC 的 npm 装配版本（[#201](https://github.com/ECNU/EduWork/pull/201)、[#202](https://github.com/ECNU/EduWork/pull/202)、[#203](https://github.com/ECNU/EduWork/pull/203)、[#208](https://github.com/ECNU/EduWork/pull/208)、[#217](https://github.com/ECNU/EduWork/pull/217)）。

<h2 id="en-048">English</h2>

Desktop packages are available for **Windows x64**, **macOS Apple Silicon (arm64)**, and the new **macOS Intel (x64)** target, with **DSH 0.2.1-rc.3**.

- **Response annotations:** Select text in an assistant reply, add comments and send several annotations together. Source numbers, editing controls and sent annotation cards build on the native composer, quotes and drafts. Included as a standalone npm plugin ([#154](https://github.com/ECNU/EduWork/pull/154), [#200](https://github.com/ECNU/EduWork/pull/200)).
- **Remote access:** Connect to your local EduWork from a phone or another computer's browser to continue conversations and respond to approval requests. Includes local pairing approval, end-to-end encrypted relay traffic and device revocation. Remote connections are off by default; deploy your own relay and configure its URL and access Key. The plugin and relay ship in one npm package, with [deployment guides in Chinese and English](https://github.com/ECNU/EduWork/tree/main/packages/dsh-remote-access/docs) ([#192](https://github.com/ECNU/EduWork/pull/192), [#205](https://github.com/ECNU/EduWork/pull/205), [#207](https://github.com/ECNU/EduWork/pull/207), [#216](https://github.com/ECNU/EduWork/pull/216)).
- **Windows installation and updates:** Improve installation guidance, shortcuts and launch options. Confirmed replacement preserves user data and rolls back on failure. Fix a possible blank screen on the first launch after a delta update that previously required reopening the application ([#147](https://github.com/ECNU/EduWork/pull/147), [#211](https://github.com/ECNU/EduWork/pull/211)).
- **Startup and runtime:** Upgrade to DSH 0.2.1-rc.3, integrate upstream menu, window and skill events, and adopt draft restoration while preserving preset and plugin choices. Add the product logo to the loading screen ([#213](https://github.com/ECNU/EduWork/pull/213), [#214](https://github.com/ECNU/EduWork/pull/214), [#215](https://github.com/ECNU/EduWork/pull/215)).
- **Plugin experience:** Localize approval prompts with the interface language. Defer mail protocol libraries, the PDF engine and search browser libraries to reduce startup loading. Update the pinned mail, literature and OIDC npm packages ([#201](https://github.com/ECNU/EduWork/pull/201), [#202](https://github.com/ECNU/EduWork/pull/202), [#203](https://github.com/ECNU/EduWork/pull/203), [#208](https://github.com/ECNU/EduWork/pull/208), [#217](https://github.com/ECNU/EduWork/pull/217)).
