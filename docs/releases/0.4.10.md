EduWork 0.4.10

[中文](#cn-0410) | [English](#en-0410)

<h2 id="cn-0410">中文</h2>

本次提供 **Windows x64**、**macOS Apple Silicon（arm64）** 与 **macOS Intel（x64）** 桌面包，内核升级至 **DSH 0.2.1-rc.5**。

- **侧边聊天**：从消息按钮或选中文字后的操作栏开启侧聊，带着原会话的历史快照在右侧继续提问，多条批注可以一起发送。侧聊与主会话分别进行，关闭后停止生成并归档，可从归档会话恢复为普通会话。侧聊与批注分别作为 npm 插件装配（[#210](https://github.com/ECNU/EduWork/pull/210)、[#253](https://github.com/ECNU/EduWork/pull/253)）。
- **远程访问**：设置页可选择自己的中继或发行版提供的机构接入，显示登录状态，测试连接并重试。修复运行中启用远控后，远端无法保存设置、确认预览版说明的问题；补充 [Docker 部署指南](https://github.com/ECNU/EduWork/blob/main/packages/dsh-remote-access/docs/DEPLOYMENT.md)（[#230](https://github.com/ECNU/EduWork/pull/230)、[#231](https://github.com/ECNU/EduWork/pull/231)、[#232](https://github.com/ECNU/EduWork/pull/232)、[#246](https://github.com/ECNU/EduWork/pull/246)）。
- **启动与恢复**：复用官方加载页展示启动等待状态，改进退出恢复；macOS 启动准备期间隐藏应用后保持后台运行。Windows 更新后的启动健康标记支持短暂文件占用重试；Host 异常退出时区分外部终止与原生崩溃，避免把陈旧的插件日志误当成原因（[#209](https://github.com/ECNU/EduWork/pull/209)、[#239](https://github.com/ECNU/EduWork/pull/239)、[#247](https://github.com/ECNU/EduWork/pull/247)、[#249](https://github.com/ECNU/EduWork/pull/249)）。
- **Office 与桌宠**：更新 Office 技能的文件验证指引，使用校验工具和 LibreOffice Kit，避免在受限环境启动桌面 Office 后卡住；修正朝右绘制的桌宠拖动、探头动画方向（[#258](https://github.com/ECNU/EduWork/pull/258)、[#259](https://github.com/ECNU/EduWork/pull/259)）。
- **决策工具**：新增独立的 SystemOne 决策插件与配套技能，可按标签分类、判断条件成立概率和按量表评分。配置服务地址、模型和认证并启用后使用，支持 API Key、机构 OIDC 或免鉴权服务（[#257](https://github.com/ECNU/EduWork/pull/257)）。
- **内核与许可**：升级 [DSH 0.2.1-rc.5](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.5)，采用改进后的思考内容展示，并纳入 rc.4 的 ACP 输出修复。项目主许可证迁移至木兰 PSL v2，保留历史 MIT 授权及第三方许可声明（[#256](https://github.com/ECNU/EduWork/pull/256)）。

<h2 id="en-0410">English</h2>

Desktop packages are available for **Windows x64**, **macOS Apple Silicon (arm64)** and **macOS Intel (x64)**, with **DSH 0.2.1-rc.5**.

- **Side chat:** Open a side conversation from a message button or text selection, bringing a snapshot of the source history into the right sidebar. Send multiple annotations together. Side conversations proceed separately from the main chat; closing stops generation and archives the conversation, which can later be restored as a regular chat. Side chat and annotations ship as separate npm plugins ([#210](https://github.com/ECNU/EduWork/pull/210), [#253](https://github.com/ECNU/EduWork/pull/253)).
- **Remote access:** Choose your own relay or an organization connection supplied by your distribution, check login status, test the connection and retry from settings. Fix remote settings writes and preview-notice confirmation after enabling the plugin while the app is running. Add [Docker deployment instructions](https://github.com/ECNU/EduWork/blob/main/packages/dsh-remote-access/docs/DEPLOYMENT_EN.md) ([#230](https://github.com/ECNU/EduWork/pull/230), [#231](https://github.com/ECNU/EduWork/pull/231), [#232](https://github.com/ECNU/EduWork/pull/232), [#246](https://github.com/ECNU/EduWork/pull/246)).
- **Startup and recovery:** Use the upstream loading page for startup status and improve quit recovery. Keep macOS in the background when hidden during startup. Retry transient Windows startup-health file locks after updates. Distinguish external Host termination from native crashes instead of presenting stale plugin output as the cause ([#209](https://github.com/ECNU/EduWork/pull/209), [#239](https://github.com/ECNU/EduWork/pull/239), [#247](https://github.com/ECNU/EduWork/pull/247), [#249](https://github.com/ECNU/EduWork/pull/249)).
- **Office and desktop pets:** Guide Office skills to use validators and LibreOffice Kit, avoiding desktop Office applications that can block in a confined environment. Correct drag and peek direction for pet artwork drawn facing right ([#258](https://github.com/ECNU/EduWork/pull/258), [#259](https://github.com/ECNU/EduWork/pull/259)).
- **Decision tools:** Add a standalone SystemOne decision plugin and skill for classification, condition probabilities and rubric scoring. Configure an endpoint, model and authentication before enabling it; API keys, organization OIDC and unauthenticated services are supported ([#257](https://github.com/ECNU/EduWork/pull/257)).
- **Runtime and licensing:** Upgrade to [DSH 0.2.1-rc.5](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.5) for improved reasoning display, also including the rc.4 ACP output fix. Adopt Mulan PSL v2 as the project license while retaining historical MIT grants and third-party notices ([#256](https://github.com/ECNU/EduWork/pull/256)).
