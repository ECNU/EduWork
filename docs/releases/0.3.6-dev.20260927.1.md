EduWork 0.3.6-dev.20260927.1 · Alpha 1

本次提供 Windows x64 和 macOS Apple Silicon 测试包，内核升级到 DSH 0.1.7-rc.2。

### 本次更新

- 技能与插件在侧栏并列展示；保留对话与 Knowledge Studio 共用的技能管理。
- 按模型类型注册：对话只展示 LLM；能读图的 LLM 仍可用于对话，生图、语音、向量和重排模型不进入对话选择器。
- 读图辅助模型增加独立并发队列与 HTTP 429 重试，减少多页图片同时分析时的限流失败。
- 复用官方 rc.2 桌面能力，改进内置浏览器、附件类型展示和旧会话导入。
- 修复配置写入失败后的恢复、登录失效提示残留和设置页深色配色；完善 Windows 更新组件缺失或无法启动时的排查提示。
- 增加桌面任务通知；改进 macOS Dock 行为，并支持 macOS 系统语音合成。

### 安装说明

Alpha 关闭软件自动更新，Skills 使用随包版本。本次只在 GitHub 发布安装包，不切换现有正式版更新入口。

Windows：完整解压到可写目录后运行 EduWork-Electron.exe。请与旧版本分目录保存；当前未进行 Windows 代码签名。

macOS：解压后将 EduWork Alpha.app 移到“应用程序”再打开。Alpha 使用独立测试数据目录，需要重新登录。仅支持 Apple Silicon，最低 macOS 15；尚无 Developer ID 签名和公证，需按系统提示允许打开。
