# 侧边聊天

**简体中文** | [English](README_EN.md)

侧边聊天从主会话的消息或选段开启，在右侧栏使用独立输入框继续提问。侧聊基于选中位置创建来源历史快照；继承的历史作为模型上下文，在侧聊界面中隐藏。主会话和侧聊独立生成与停止。

同一主会话可以有多个侧聊。引用时，优先使用当前聚焦且覆盖该内容的侧聊；否则按创建顺序选择第一个可覆盖的侧聊。所有现有快照均不覆盖时，创建新的侧聊。

例如，快照 A、B、C 按时间从旧到新排列：引用 C 新增的内容时使用 C；引用 B 的内容时，若当前聚焦 B 或 C 则使用当前侧聊，否则按创建顺序在 B、C 中选择。引用比 C 更新的内容则创建新的侧聊。

流式回复选段随引用携带选中时的可见上下文；超长内容与来源上下文的具体限制见[插件说明](../../../packages/dsh-side-chat/README.md)。关闭侧聊会停止生成并归档，历史可在归档会话中查看或恢复；强制退出时未经归档的记录可能作为普通会话保留。

侧聊与批注由独立插件实现，关闭通过 DSH Workspace 公开接口归档，不修改 DSH Runtime 或 UI bundle。界面通过原生 DOM 标记隐藏继承历史；模型是否复用 KV cache 由模型服务决定。
